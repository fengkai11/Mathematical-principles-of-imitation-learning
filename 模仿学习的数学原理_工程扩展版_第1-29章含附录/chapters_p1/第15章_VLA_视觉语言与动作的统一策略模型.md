# 第15章：VLA：视觉、语言与动作的统一策略模型

> **P1 章节体验卡**：本章的主角不是“大模型很强”，而是多模态条件策略。VLA 的数学位置是：把视觉、语言、本体状态、动作历史和任务目标统一为动作生成的条件。

## 本章要解决的问题

```text
为什么机器人策略需要同时理解视觉、语言和动作？
VLA 中的 token 化到底在组织什么信息？
代表模型如何定位到模仿学习主线中？
```

## 本章核心数学对象

```text
多模态上下文 c_t^{VLA}
VLA 条件策略 πθ(a_t|c_t^{VLA})
动作 token / 连续动作头
```

其中最关键的是 $c_t^{VLA}$：它不是一个模型名字，而是策略条件变量的扩展。

## 读者防卡点

- VLA 不是把语言模型直接搬到机器人上，而是把视觉、语言和动作统一成条件策略问题。
- 动作可以离散 token 化，也可以通过连续动作头生成，二者工程取舍不同。
- OpenVLA、Octo、π0 等模型要放在“多任务、多模态、通用策略”的谱系中理解。

## 推块入槽落点

在推块入槽任务中，VLA 可以根据图像识别方块和槽位，根据语言理解“把红色方块推入左侧槽”，再结合动作历史输出下一步动作。

## 读完本章，你应该能判断什么

读完本章，应该能判断一个 VLA 方法主要解决的是多模态条件组织、动作生成头，还是大规模数据泛化问题。

## 本章如何引出下一章

VLA 能生成动作，但它不必然知道动作后果。下一篇开始追问：如果执行这个动作，未来世界会怎样？
