# 第17章：World Models、World Action Models 与 JEPA：机器人要学会预测动作后果

> **P1 章节体验卡**：本章要把世界模型从泛泛概念压回一个问题：给定当前世界表示和候选动作，模型能否预测未来任务相关表示？重点不是预测得越细越好，而是预测是否服务控制、验证和安全判断。

## 本章要解决的问题

```text
World Model、WAM、JEPA 分别在预测什么？
为什么不一定要预测完整像素？
为什么预测误差小不必然推出控制效果好？
```

## 本章核心数学对象

```text
latent world state h_t
动作条件世界预测 pφ(h_{t+1:t+H}|h_t,A_t,c_t)
JEPA 式表示预测
```

其中最关键的是动作条件预测：不是只问世界会怎样，而是问“如果执行这个动作块，世界会怎样”。

## 读者防卡点

- World Model 不是只能预测图像，也可以预测 latent 表示或任务变量。
- WAM 的核心是动作条件：不同动作会导致不同未来。
- 预测误差低不等于控制成功，因为控制还涉及目标、约束、风险和反馈。

## 推块入槽落点

在推块入槽任务中，WAM 需要预测：执行某个推块动作后，方块会靠近槽口、卡住、滑开，还是撞到边缘。JEPA 式预测可以关注方块—槽口关系，而不是完整重建桌面像素。

## 读完本章，你应该能判断什么

读完本章，应该能判断一个世界模型是在预测像素、预测表示，还是在预测动作条件后果；也应该知道预测准确和控制成功之间不能画等号。

本章定义了世界预测对象。下一章会讨论这些预测如何进入实际策略系统：用于计划、候选动作验证、安全边界和失败恢复。
