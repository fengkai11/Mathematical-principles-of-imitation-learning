# 第二篇导读：动作分布、轨迹损失与隐变量策略

> **本篇一句话导读**：第一篇已经说明，Behavior Cloning 在专家分布上拟合动作，但闭环执行时会因为分布偏移而失败。第二篇继续追问：策略输出到底应该是什么？是一个单步动作、一个动作序列、一个概率分布，还是一个带隐变量的生成模型？

---

## 1. 为什么第3章之后需要第二篇

第一篇建立了模仿学习的第一条主线：

```text
专家轨迹
→ 策略
→ 闭环执行
→ 执行分布
→ 分布偏移
→ 数据分布修正
```

第3章说明了一个关键事实：策略一旦开始自己执行，它看到的状态分布就可能不同于专家数据分布。DAgger 的思路是把学习策略会遇到的状态重新纳入训练数据。

但这还没有回答另一个问题：

> 就算训练数据覆盖得更好，策略本身应该如何表达动作？

如果一个状态下只有一个明确动作，普通 BC 也许够用。但机器人任务经常不是这样。

例如二维绕障、抓取、放置、插入任务中，同一个观测下可能存在多种合理动作：

```text
可以从左侧绕，也可以从右侧绕；
可以先调整姿态，也可以先靠近目标；
可以快一点抓取，也可以慢一点保证安全；
可以一次输出单步动作，也可以输出未来一小段动作块。
```

如果策略只能输出一个点估计，MSE 可能会把多个合理动作平均成一个坏动作。第5章会专门解释这个“均值陷阱”。

因此，第二篇要把读者从“单步动作标签拟合”推进到“动作表达方式”的层面：

```text
单步动作
→ 动作序列 / 动作块
→ 条件动作分布
→ 多峰动作问题
→ 隐变量策略
→ CVAE 可训练生成模型
```

---

## 2. 本篇包含章节

第二篇包含三章：

- 第4章：从单步动作到动作序列：轨迹损失与动作块
- 第5章：从点估计到动作分布：概率策略、MSE 与多峰陷阱
- 第6章：隐变量策略与 CVAE：从多模式动作到可训练生成模型

这三章的关系可以理解为：

```text
第4章：不要每次只看一步动作，而要把短时动作序列作为策略输出对象。
第5章：不要只把策略理解成确定性函数，而要把它理解成条件动作分布。
第6章：当动作分布是多峰的，用隐变量和 CVAE 表达多种动作模式。
```

## 3. 第二篇的数学主线

本篇的数学主线可以写成：

```text
第3章：BC 在闭环中会发生分布偏移
→ 第4章：单步动作 a_t 扩展为动作块 A_t=a_{t:t+H}
→ 动作块策略 πθ(A_t|c_t)
→ 第5章：点估计策略 a=fθ(s) 的局限
→ MSE 最优点估计是条件均值
→ 概率策略 πθ(a|s) 表达条件动作分布
→ 第6章：隐变量 z 表示动作模式
→ 隐变量边缘动作分布 πθ(a|s)=∫πθ(a|s,z)p(z|s)dz
→ CVAE 用 encoder / decoder / prior 训练隐变量策略
→ 第7章 IRL：如果动作模式不唯一，专家背后的偏好是什么？
```

每一章都在回答上一章留下的问题：

| 章节 | 承接的问题 | 本章推进 | 留给下一章的问题 |
|---|---|---|---|
| 第4章 动作块 | 第3章说明闭环误差会累积，但策略仍是单步输出 | 把策略输出从单步动作扩展为短时动作序列 | 如果同一状态下有多个合理动作，动作块是否仍然可能被平均？ |
| 第5章 概率策略 | 单步或动作块都可能存在多种合理答案 | 说明 MSE 会学条件均值，引入条件动作分布 | 如果条件动作分布是多峰的，如何表达不同模式？ |
| 第6章 CVAE | 概率策略需要表达多峰动作模式 | 引入隐变量、encoder、decoder、prior 和 ELBO | 多种动作模式背后是否存在更高层专家偏好？ |

## 4. 本篇新增数学对象

| 数学对象 | 符号 | 一句话含义 | 工程对应物 | 后续作用 |
|---|---|---|---|---|
| 动作块 | $A_t=a_{t:t+H}$ | 从当前时刻开始的一小段动作序列 | 未来几步末端位姿增量、夹爪命令或控制序列 | 第10章 ACT、第11章 Diffusion Policy、第12章 Flow Matching 复用 |
| 条件上下文 | $c_t$ | 生成动作所依据的信息 | 当前观测、历史、语言、目标或任务条件 | 后文统一写成策略条件 |
| 动作块策略 | $\pi_\theta(A_t\mid c_t)$ | 根据上下文生成动作序列的策略 | 一次预测未来一段控制 | 现代机器人策略模型的统一形式 |
| 点估计策略 | $\hat a=f_\theta(s)$ | 给定状态只输出一个动作 | 普通连续动作回归 | 用于解释 MSE 的局限 |
| 条件动作分布 | $\pi_\theta(a\mid s)$ | 给定状态输出动作概率分布 | 多个合理抓取方向、绕障方向或插入策略 | 后文所有生成式策略的基础 |
| 隐变量 | $z$ | 表示未显式标注的动作模式 | 抓取风格、接近方向、节奏、任务阶段 | CVAE、生成式策略和多峰建模 |
| encoder | $q_\phi(z\mid s,a)$ | 训练时根据状态和动作推断隐变量 | 训练时“偷看答案”的推断器 | CVAE 训练用 |
| decoder | $p_\theta(a\mid s,z)$ | 根据状态和隐变量生成动作 | 推理时真正生成动作的模型 | 后续生成式策略直接复用 |
| prior | $p_\psi(z\mid s)$ | 推理时从状态预测隐变量来源 | 没有专家动作时选择动作模式 | CVAE 推理与采样用 |

## 5. 本篇公式主线

第二篇的公式不只是写法变化，而是在逐步回答“策略如何表达动作”。

```text
动作块：A_t=a_{t:t+H}
→ 动作块策略：πθ(A_t|c_t)
→ 点估计策略：a=fθ(s)
→ MSE 风险：R(u|s)
→ MSE 最优解：u*(s)=E[a|s]
→ 概率策略：πθ(a|s)
→ 隐变量条件策略：πθ(a|s,z)
→ 隐变量边缘分布：πθ(a|s)=∫πθ(a|s,z)p(z|s)dz
→ CVAE encoder / decoder / prior
→ CVAE 损失与 ELBO
```

读本篇时，不要只问“公式怎么背”，而要问：

```text
这个公式是在改变策略输出对象，还是在改变动作分布建模方式？
它解决了单步动作拟合的哪个局限？
它会在第四篇现代策略模型中如何复用？
```

## 6. 统一工程主线：视觉引导机械臂抓取与放置

阅读本篇时，可以始终把公式落回一个统一工程任务：

```text
机器人通过相机观测桌面上的物体，输出末端位姿增量或动作序列，完成抓取并放置到目标区域。
```

在这个任务中：

- $s_t$ 可以理解为真实世界状态，例如物体位姿、机械臂状态、接触状态、夹爪是否打滑；
- $o_t$ 是机器人实际看到的观测，例如图像、本体状态、历史帧或视觉特征；
- $c_t$ 是策略使用的条件信息，可以包括当前观测、历史、语言指令和任务目标；
- $a_t$ 是单步动作，例如末端速度、关节增量或夹爪命令；
- $A_t$ 是未来一小段动作序列；
- $z$ 可以表示抓取风格、接近方向、动作节奏或任务阶段。

例如，机器人要抓取桌面上的杯子，同一个观测下可能有多种合理策略：

```text
从左侧接近杯子；
从右侧接近杯子；
先旋转夹爪再靠近；
先靠近再调整姿态；
快速抓取；
保守慢速抓取。
```

如果只用确定性 MSE，模型可能学到这些动作的平均值。平均动作未必对应任何真实可行策略。第二篇要解决的就是这种动作表达问题。

## 7. 和第三篇、第四篇的关系

第二篇向第三篇留下一个问题：

> 如果同一状态下有多种合理动作，这些动作背后是否有共同的专家偏好？

这就是第7章 IRL 要回答的问题。第7章会从动作模式继续上升到 reward、轨迹回报和专家偏好。

第二篇也为第四篇打地基。第10章 ACT、第11章 Diffusion Policy、第12章 Flow Matching 都不是凭空出现的，它们都复用第二篇的核心对象：

```text
动作块 A_t
条件动作分布 πθ(A_t|c_t)
多峰动作分布
生成式动作策略
离线数据上的训练目标
```

因此，第二篇在全书中的位置很关键：它把第一篇的“闭环分布问题”连接到后文的“现代动作生成模型”。

## 8. 读完第二篇，你应该能判断什么

| 工程现象 | 应该想到的第二篇判断 |
|---|---|
| 单步动作预测抖动，轨迹不连贯 | 可能需要从单步动作改为动作块或短时动作序列 |
| 同一状态下专家动作不一致 | 可能不是标注噪声，而是多种合理动作模式 |
| MSE loss 低，但动作撞向中间区域 | MSE 可能学到了多峰分布的条件均值 |
| 想让策略输出多个候选动作 | 需要把策略理解成条件动作分布，而不是确定函数 |
| 想表达左绕、右绕、不同抓取风格 | 可以引入隐变量 $z$ 表示动作模式 |
| CVAE 训练能用动作，推理时却没有动作 | encoder 是训练时推断工具，decoder 和 prior 才构成推理策略 |
| 准备进入 ACT / Diffusion Policy | 先确认动作块、条件分布和多峰动作问题已经理解 |

## 9. 本篇小结

第二篇完成了从第3章到第7章之间的关键桥接。

第3章说明了 BC 的闭环分布偏移问题。第二篇进一步说明：即使数据覆盖问题被缓解，策略输出形式本身也会限制模仿学习能力。机器人任务不是每次只预测一个单步动作，也不是每个状态只有一个标准答案。

因此，第二篇把策略表达从：

```text
单步确定动作
```

推进到：

```text
动作块
→ 条件动作分布
→ 多峰动作模式
→ 隐变量生成式策略
```

进入第7章之前，读者应该已经理解：

```text
动作可以有多种合理模式；
策略需要能表达这种多样性；
但动作模式为什么合理，还需要从专家偏好和行为分布角度继续解释。
```
