# 第五篇导读：从历史上下文到多模态条件策略

第10章到第13章已经回答了现代机器人策略模型中的一个核心问题：动作分布如何被建模和生成。

第四篇的主线是：

```text
BC：点估计动作；
ACT：隐变量动作块；
Diffusion Policy：从噪声中逐步生成动作块；
Flow Matching：沿连续速度场生成动作块；
第13章：对这些动作策略模型做阶段性对比。
```

第五篇接在第13章之后，不再继续问“动作头怎么生成动作”，而是换一个角度问：

```text
策略在生成动作之前，应该依据什么上下文做决策？
```

因此，本篇的数学主线不是 Transformer、SSM、Mamba 或 VLA 这些模型名字本身，而是条件策略：

$$\pi_\theta(a_t\mid c_t)$$

其中，条件变量 $c_t$ 会逐步扩展：

```text
c_t = o_t
→ c_t = (o_{t-K+1:t}, a_{t-K+1:t-1}, g)
→ c_t = c_t^{VLA} = (I_{1:t}, q_{1:t}, a_{1:t-1}, l)
```

这条线把第五篇拉回全书数学主线：现代策略模型不只是换一个动作头，也是在扩展策略可以利用的上下文。

## 本篇包含章节

- **第14章：序列策略模型：从 Decision Transformer 到 Transformer Policy**
- **第15章：VLA：视觉、语言与动作的统一策略模型**

原“架构选择总结”已经压缩进第15章末尾，作为 VLA 之后的工程选型收束：BC、ACT、Diffusion、Flow 主要回答动作怎么生成；Decision Transformer、Transformer Policy、SSM / Mamba、VLA 主要回答上下文怎么组织。

## 本篇在全书中的作用

第四篇回答“动作如何被预测或生成”。第五篇进一步回答“动作生成之前，策略依赖什么条件信息”。

在机械臂抓取、放置和治具插入主线中，这个差别非常具体。

如果策略只依赖当前图像，它可能不知道夹爪是否已经接触工件、刚才是否插入失败、是否正在恢复、当前动作应该继续推进还是先回退。这时需要历史上下文。

**公式：历史上下文条件策略**

$$\pi_\theta(a_t\mid c_t)$$

其中：

$$c_t=(o_{t-K+1:t},a_{t-K+1:t-1},g)$$

如果任务目标由语言指定，机器人还需要知道“抓红色杯子”和“抓蓝色杯子”之间的差别，也需要把视觉、本体状态、历史动作和语言指令统一成多模态上下文。

**公式：VLA 多模态上下文**

$$c_t^{VLA}=(I_{1:t},q_{1:t},a_{1:t-1},l)$$

于是策略写成：

$$\pi_\theta(a_t\mid c_t^{VLA})$$

因此，第14章的主角不是 Transformer，而是上下文 $c_t$；第15章的主角也不是大模型，而是多模态上下文 $c_t^{VLA}$。

---

## 第14章的数学定位

第14章回答的问题是：为什么 Markov 形式的单帧策略可能不够？

单帧策略写成：

$$\pi_\theta(a_t\mid o_t)$$

历史条件策略写成：

$$\pi_\theta(a_t\mid c_t)$$

其中：

$$c_t=(o_{t-K+1:t},a_{t-K+1:t-1},g)$$

Decision Transformer、Transformer Policy、SSM / Mamba 的共同位置是：它们都是不同的历史上下文编码方式。它们不改变“模仿学习仍然在条件上下文上预测动作”这个事实。

第14章要防止读者产生一个误解：

```text
用了 Transformer，就从模仿学习变成了万能强化学习。
```

更准确的理解是：

```text
Transformer Policy = 更强的上下文编码器 + 条件动作预测。
```

## 第15章的数学定位

第15章回答的问题是：当任务条件来自视觉、语言、本体状态和历史动作时，策略应该如何写？

VLA 的核心不是“让语言模型控制机器人”，而是把条件变量扩展为：

$$c_t^{VLA}=(I_{1:t},q_{1:t},a_{1:t-1},l)$$

于是策略写成：

$$\pi_\theta(a_t\mid c_t^{VLA})$$

这说明 VLA 没有自动摆脱模仿学习的数据覆盖问题。它只是让策略可以依赖更丰富的上下文。如果训练数据没有覆盖夹爪偏位、工件遮挡、槽口变形、抓取失败后的恢复动作，VLA 在实机中仍然可能失败。

## 与第六篇的衔接

第五篇回答的是：

```text
策略生成动作之前，应该看什么上下文？
```

第六篇继续追问：

```text
策略生成动作之后，机器人是否知道这个动作会带来什么后果？
```

这就是从第五篇到第六篇的转折。

```text
第五篇：上下文条件策略 pi_theta(a_t | c_t)
第六篇：动作条件世界预测 p_phi(h_{t+1} | h_t, a_t)
```

前者回答“根据上下文做什么”，后者回答“这样做之后会怎样”。

## 阅读提醒

阅读本篇时，不要只关注模型名字，而要始终追问四个问题：

1. 这个方法到底扩展了动作生成方式，还是扩展了条件上下文？
2. 这里的条件变量 $c_t$ 是什么？它包含当前观测、历史、语言，还是多模态输入？
3. 训练时模型看到的上下文和部署时自己闭环诱导出的上下文是否一致？
4. 上下文表达能力提升之后，数据、延迟、安全和调试成本是否仍然可控？

本篇读完后，读者应该形成一个判断：

```text
Transformer、SSM、Mamba、VLA 不是模仿学习的新目标，
而是条件策略 pi_theta(a_t | c_t) 中上下文 c_t 的不同组织方式。
```
