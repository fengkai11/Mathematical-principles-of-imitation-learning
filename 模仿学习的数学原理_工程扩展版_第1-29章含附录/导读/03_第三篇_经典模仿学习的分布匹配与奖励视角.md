# 第三篇导读：经典模仿学习的分布匹配与奖励视角

> **本篇一句话导读**：第二篇已经说明动作存在多模态，策略可以用概率分布和隐变量表达多种合理动作。第三篇继续追问：如果只模仿单步动作不够，我们应该在什么层面理解专家行为？答案会从 reward、轨迹回报、occupancy measure，一直推进到离线数据近似覆盖区域与 OOD 风险。

---

## 1. 为什么第6章之后需要第三篇

第6章 CVAE 解决了一个关键问题：同一个状态下不一定只有一个正确动作。机器人可以通过隐变量表达多种动作模式，例如从左侧绕、从右侧绕、先调整姿态再接近。

但这还没有回答一个更高层的问题：

> 为什么这些不同动作模式都是合理的？专家行为背后是否存在更高层的偏好结构？

在机器人控制中，专家不是随机移动机械臂，而是在隐式权衡安全、效率、平顺、成功率、接触风险和恢复能力。因此，第6章之后自然进入第三篇：从“动作如何表达”推进到“专家行为分布和专家偏好如何理解”。

第三篇不是三个经典方法的并列介绍，而是一次对象升级：

```text
第6章：隐变量策略表达多种动作模式
→ 第7章：IRL 追问专家背后的 reward 偏好
→ 第8章：GAIL 绕开显式 reward，直接匹配 occupancy measure
→ 第9章：Offline IL 分析固定离线数据的覆盖和 OOD 风险
```

---

## 2. 本篇包含章节

- 第7章：IRL：专家到底在优化什么
- 第8章：GAIL：从判别器里偷一个奖励函数
- 第9章：Offline Imitation Learning：离线数据不是越多越好，是坑有没有录进去

这三章的关系可以理解为：

```text
第7章 IRL：从专家轨迹反推 reward，解释专家为什么这样做。
第8章 GAIL：绕开显式 reward，直接匹配专家与策略的 occupancy measure。
第9章 Offline IL：当不能在线 rollout 时，重新审视离线数据近似覆盖区域、support mismatch 和 OOD action。
```

---

## 3. 第三篇的数学主线

本篇的数学主线可以写成：

```text
第6章：隐变量策略 pi_theta(a|s,z)
→ 第7章：引入 reward r(s,a) 和轨迹回报 R(tau)
→ IRL：从专家轨迹反推能解释专家行为的 reward
→ reward ambiguity：同一专家行为可能被多个 reward 解释
→ maximum entropy IRL：用概率分布描述专家轨迹偏好
→ 第8章：从 reward inference 转向 occupancy measure matching
→ GAIL：用判别器比较专家和策略的 rho_pi(s,a)
→ 第9章：当 rollout 受限时，离线数据近似覆盖区域 C_epsilon(D) 成为核心约束
→ OOD action：动作出圈会继续改变后续状态分布
→ 第10章 ACT：在离线数据现实下，用动作块表达短时连续控制
```

每一章都回答上一章留下的问题：

| 章节 | 承接的问题 | 本章推进 | 留给下一章的问题 |
|---|---|---|---|
| 第7章 IRL | 第6章说明动作可以多模态，但专家为什么偏好这些行为还没有解释 | 引入 reward、轨迹回报、特征期望和 reward ambiguity | 如果 reward 不唯一且难恢复，能不能直接匹配行为分布？ |
| 第8章 GAIL | IRL 显式恢复 reward 存在歧义和求解困难 | 引入 occupancy measure 和对抗分布匹配 | 如果 GAIL 需要 rollout，真实机器人不能随便试错怎么办？ |
| 第9章 Offline IL | 在线 rollout 有安全、成本和设备风险 | 引入 behavior policy、近似覆盖区域、support mismatch、OOD action 和 recovery data | 在固定数据上，如何用更强策略模型学习动作序列和多模态动作？ |

## 4. 本篇新增数学对象

| 数学对象 | 符号 | 一句话含义 | 工程对应物 | 后续作用 |
|---|---|---|---|---|
| 奖励函数 | $r(s,a)$ | 描述某个状态—动作好坏的标量函数 | 安全、平顺、效率、成功率、碰撞风险等偏好 | IRL、RL、后训练与策略评估 |
| 轨迹回报 | $R(\tau)$ | 一整条轨迹累计得到的 reward | 一次抓取、一次装配或一次泊车全过程质量 | 连接轨迹级目标与专家偏好 |
| 特征函数 | $f(s,a)$ | 从状态—动作中提取可比较的任务特征 | 距离、速度、碰撞余量、姿态误差、接触状态 | 线性 reward 与特征匹配 |
| 特征期望 | $\mu(\pi)$ | 策略执行后访问到的特征平均统计 | 一批轨迹中的安全距离、平顺性、成功状态统计 | IRL 中比较专家和学习策略 |
| 最大熵轨迹分布 | $p_w(\tau)$ | 用 reward 给轨迹分配概率，同时保留多种可能行为 | 专家不是只有一条唯一正确轨迹 | 最大熵 IRL 与生成式视角 |
| 占用测度 | $\rho_\pi(s,a)$ | 策略闭环执行时访问状态并执行动作的频率 | 模型实际会走到哪里、做什么 | GAIL、分布匹配和后续评估 |
| 判别器 | $D_\omega(s,a)$ | 判断状态—动作样本更像专家还是当前策略 | 行为分布的“质检员” | GAIL 中产生隐式 reward |
| 行为策略 | $\beta(a\mid s)$ | 产生离线数据的策略 | 遥操作员、旧模型、规则系统或混合数据源 | Offline IL / Offline RL 数据来源分析 |
| 数据近似覆盖区域 | $\mathcal{C}_\epsilon(\mathcal{D})$ | 离线数据样本及其附近的可插值区域 | 训练集中见过或足够相似的正常、边界、失败和恢复场景 | 判断 support mismatch 和 OOD 风险 |
| OOD 动作 | OOD action | 超出数据覆盖范围的动作 | 夹爪乱动、车速过大、末端姿态异常、恢复动作缺失 | 离线策略部署风险分析 |

**关于 support 的读者提示**：在连续状态和连续动作空间中，有限数据集不可能严格覆盖每个点。本篇后续提到 support 时，默认采用工程近似理解：它指数据样本及其附近的可插值区域，也就是第9章中的 $\mathcal{C}_\epsilon(\mathcal{D})$。

## 5. 本篇公式主线

建议读者把本篇公式按下面关系理解：

```text
隐变量策略 pi_theta(a|s,z)
→ reward r(s,a)
→ 轨迹回报 R(tau)
→ 线性 reward r_w(s,a)
→ 特征期望 mu(pi)
→ 最大熵轨迹分布 p_w(tau)
→ occupancy measure rho_pi(s,a)
→ GAIL 的 min-max 分布匹配目标
→ 离线数据 D 与 behavior policy beta
→ 近似覆盖区域 C_epsilon(D) 与 OOD action
```

读本篇时，不要只问“这个公式怎么背”，而要问：

```text
这个公式把模仿学习推进到了哪个层面？
它是在解释专家偏好、匹配行为分布，还是分析离线数据风险？
它解决了上一章什么问题？
它又暴露了什么新的局限？
```

## 6. 第三篇分布符号关系表

| 符号 | 出现章节 | 含义 | 数据或策略来源 | 读者要避免的误解 |
|---|---|---|---|---|
| $\mathcal{D}_E$ | 第7、8章 | 有限专家轨迹或专家状态—动作数据 | 专家、遥操作员、老师傅采样得到 | 不等于完整专家分布，只是有限样本 |
| $p_\pi(\tau)$ | 第7章 | 策略 $\pi$ 闭环执行诱导出的轨迹分布 | 策略与环境转移共同决定 | 不是固定数据集，而是策略执行后的分布 |
| $p_w(\tau)$ | 第7章 | MaxEnt IRL 中由 reward 权重 $w$ 诱导的轨迹概率 | reward、动力学和可行轨迹共同决定 | 不是专家真实心理模型，只是概率建模假设 |
| $\rho_E(s,a)$ | 第8章 | 专家 occupancy measure | 专家策略或专家数据背后的理论访问分布 | 不等于有限样本本身 |
| $\rho_\pi(s,a)$ | 第8章 | 当前策略 occupancy measure | 当前策略 rollout 产生 | 会随策略更新而变化 |
| $\rho_\beta(s,a)$ | 第9章 | behavior policy 诱导的数据分布 | 采集离线数据的策略 | 不等于部署策略分布 |
| $\rho_{\pi_\theta}(s,a)$ | 第9章 | 部署策略诱导的分布 | 当前训练出的策略闭环执行 | 部署风险发生在这里 |
| $\mathcal{C}_\epsilon(\mathcal{D})$ | 第9章 | 离线数据近似覆盖区域 | 固定数据集及其邻域 | 不是全部安全区域 |

## 7. 本篇小结

第三篇完成了从第6章到第10章之间的关键桥接。

第6章说明策略可以表达多种动作模式。第7章进一步追问专家动作模式背后的偏好结构；第8章把显式 reward 恢复转化为 occupancy measure matching；第9章提醒读者，在真实机器人中，rollout 成本高，离线数据覆盖和恢复数据比单纯数据量更重要。

因此，进入第10章 ACT 之前，读者应该已经理解：

```text
动作模型再强，也只能在数据和闭环分布允许的范围内发挥作用。
如果离线数据没有覆盖偏差、失败早期和恢复动作，强模型也可能只是更强地拟合数据缺口。
```
