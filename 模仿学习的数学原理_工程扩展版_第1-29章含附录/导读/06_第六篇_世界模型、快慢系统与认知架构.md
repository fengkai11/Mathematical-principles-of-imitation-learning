# 第六篇导读：从动作模仿到世界预测

> **本篇一句话导读**：第五篇已经说明，现代策略可以在历史、视觉、语言和动作上下文中生成动作。第六篇继续追问：只会生成动作是否足够？真实机器人还需要预测动作执行之后世界会怎样变化，并用这种预测辅助计划、验证、安全判断和失败恢复。

---

## 1. 上一篇留下的问题

第五篇把策略写成多模态条件策略：

```text
πθ(a_t | c_t^{VLA})
```

它回答的是：

```text
给定当前图像、语言、历史动作和本体状态，策略应该输出什么动作？
```

但真实机器人还要问：

```text
如果执行这个动作，未来世界会怎样？
```

在推块入槽任务中，VLA 可能输出“继续向右推”。但继续向右推可能导致：

```text
方块顺利入槽；
方块撞到槽口边缘；
方块滑开；
方块卡住；
机器人进入不可恢复状态。
```

这就是第六篇出现的原因。

---

## 2. 本篇解决的问题

第六篇把问题从“动作生成”推进到“动作后果预测”：

```text
条件策略生成候选动作
→ 世界模型预测未来表示
→ WAM 预测动作条件后果
→ JEPA 式表示预测避免只重建像素
→ 用预测结果辅助计划、验证、安全边界和失败恢复
```

本篇新增核心对象是：

```text
pφ(h_{t+1:t+H} | h_t, A_t, c_t)
```

它回答：

```text
在当前世界表示 h_t 和上下文 c_t 下，如果执行动作块 A_t，未来世界表示会怎样变化？
```

## 3. 本篇包含章节

- 第16章：从动作模仿到世界预测：机器人不能只会背动作表
- 第17章：World Models、World Action Models 与 JEPA：机器人要学会预测动作后果

三章之间的关系是：

```text

第17章：定义 World Model、WAM、JEPA 和动作条件未来预测。
第18章：说明世界预测如何进入策略系统，用于计划、验证和安全边界。
```

---

## 4. 贯穿例子：推块入槽

在推块入槽任务中，第六篇的对应关系是：

```text
World Model：预测方块未来位置和槽口关系。
WAM：预测“执行这个动作块后”方块会入槽、偏离还是卡住。
JEPA：预测任务相关表示，而不是必须重建完整像素。
计划验证：比较多个候选推法，选择风险更低的动作。
安全边界：如果预测会撞边、卡住或不可恢复，就拒绝执行或切换恢复策略。
```

---

## 5. 本篇的边界

第六篇不把“快慢系统”作为正书主线，也不展开泛泛的认知架构综述。快慢系统只作为工程补充出现，用来说明：当世界预测、任务计划和低层控制频率不一致时，系统通常需要时间尺度分工、异步缓存和 fallback。

本篇的主线始终是：

```text
动作模仿
→ 动作后果预测
→ 策略验证与安全边界
```


---

## 7. 本篇核心命题

- 只学动作不能保证理解动作后果。
- 世界预测误差小不必然推出控制效果好。
- 世界模型必须和任务目标、风险评分、计划验证和安全边界结合。
