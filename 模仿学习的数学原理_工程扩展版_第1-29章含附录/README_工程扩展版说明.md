# 《模仿学习的数学原理》六篇版说明

本版本将正书内容收束为 **第一篇到第六篇，共 21 章**。原第七篇、第八篇的后训练、实机部署、工程架构、可信评估与数据闭环内容，已从正书主线中剥离，作为工程扩展材料存档。

当前正书的核心目标是：

> 围绕模仿学习的数学对象升级链，把“从专家示范中学习一个能够闭环执行的策略”这件事讲清楚。

这条数学主线是：

```text
πθ(a|o)
→ pπ(τ)
→ ρπ(s,a)
→ pθ(A_t|o_t)
→ πθ(a_t|c_t)
→ pφ(h_{t+1:t+H}|h_t,A_t,c_t)
```

对应的问题升级是：

```text
单步动作模仿
→ 闭环轨迹分布
→ 专家行为分布匹配
→ 动作块条件生成
→ 历史、多模态和语言条件策略
→ 动作后果预测
```

本版本仍保留统一工程例子：

> **视觉引导机械臂抓取与放置任务**。

这条主线不是新增一个独立项目教程，而是作为全书统一例子：读者在学习状态、观测、动作、轨迹、策略、BC、DAgger、ACT、Diffusion Policy、VLA 和 World Model 时，都可以回到同一台机械臂、同一批遥操作示范、同一个“从抓取到放置”的连续控制任务中理解公式。

## 写作缘起

本书的写作受到赵世钰老师《强化学习的数学原理》的重要启发。赵老师的这本书给我很大触动：它并不是简单罗列强化学习算法，而是从基本概念、数学结构和问题动机出发，逐步引出 Bellman 方程、动态规划、蒙特卡洛方法、时序差分、值函数近似和策略梯度等内容。更难得的是，它在保持数学严谨性的同时，非常重视读者的理解路径：公式不是为了显示复杂，而是为了回答“这个问题为什么这样定义”“这个算法为什么这样设计”“它为什么能够工作”。

在学习和使用模仿学习相关方法时，我发现模仿学习同样需要这样一本面向工程读者、但又不回避数学原理的教材。Behavior Cloning、DAgger、IRL、GAIL、ACT、Diffusion Policy、VLA 等方法看似分散，但它们背后都围绕同一个核心问题展开：如何从专家示范中学习一个能够闭环执行的策略。本书希望借鉴《强化学习的数学原理》的写作精神，以“数学清楚、动机清楚、工程含义清楚”为原则，从专家示范、观测、动作、轨迹和策略函数出发，逐步展开模仿学习的核心问题、经典方法和现代机器人应用。

因此，这本《模仿学习的数学原理》不是对某一本书的复刻，而是一次面向模仿学习与机器人策略学习方向的再组织：既希望保留数学推导的清晰性，也希望让具有工程背景的读者能够把每一个公式落回真实任务中理解。

## 全书主线：视觉引导机械臂抓取与放置

为了避免全书变成“模仿学习主题百科”，本版把一个机器人操作任务作为统一叙事中心：

```text
人类通过遥操作示范机械臂完成抓取与放置
→ 系统记录图像、本体状态、夹爪状态和专家动作
→ 策略模型从示范数据中学习观测到动作的映射
→ 策略闭环控制机械臂执行任务
→ 通过世界预测理解动作后果和失败风险
```

这条主线按三层展开：

1. **Toy 版：二维夹爪接近任务**  
   用于解释状态、观测、动作、轨迹、BC、分布偏移和 DAgger。

2. **Standard 版：6DoF 机械臂抓取与放置**  
   用于解释连续动作回归、多模态动作、隐变量、CVAE、ACT、Diffusion Policy 和 Flow Matching。

3. **Advanced 版：语言条件下的多物体长时序操作**  
   用于解释 Transformer Policy、VLA、World Model、World Action Model 和动作后果预测。

后续章节修订时，每章都应尽量回答同一个问题：

> 本章的数学概念，在机械臂抓取与放置任务中到底解决了哪一种具体失败？
