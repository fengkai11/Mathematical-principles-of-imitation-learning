# 前沿模型定位：从 ACT 到 VLA 与世界模型

> 本文档用于把现代机器人策略模型放回《模仿学习的数学原理》的主线中。它不是论文综述，而是回答：这些前沿模型分别解决了模仿学习链条中的哪个问题？

---

## 1. 总体谱系

```text
BC
  ↓
DAgger：修正训练分布与执行分布不一致
  ↓
CVAE / Implicit BC：表达多峰动作分布
  ↓
GAIL / Offline IL：从动作拟合走向行为分布与数据覆盖
  ↓
ACT：动作块 + 隐变量，适合短时连续控制
  ↓
Diffusion Policy：动作分布的去噪生成
  ↓
Flow Matching / π0：连续流场生成动作
  ↓
Octo / OpenVLA：多任务、多模态、通用机器人策略
  ↓
World Model / WAM / JEPA：从动作模仿走向动作后果预测
```

---

## 2. ACT 的位置：动作块不是多输出几个动作

ACT 的主线位置是：

```text
单步动作预测
→ 动作块 A_t
→ 隐变量动作块策略
→ temporal ensemble
```

ACT 回答的问题是：

```text
机器人控制为什么不能每次只想一步？
```

在推块入槽任务中，ACT 不是简单预测下一步推哪里，而是一次输出“靠近—轻推—修正”的短时动作块。

---

## 3. Diffusion Policy 的位置：动作空间中的条件生成模型

Diffusion Policy 的主线位置是：

```text
条件动作块分布 p(A_t|c_t)
→ 正向加噪
→ 反向去噪
→ 从噪声中生成动作块
```

Diffusion Policy 回答的问题是：

```text
当同一条件下存在多种合理动作块时，如何生成其中一条可执行动作？
```

它不是为了把图像生成模型搬到机器人上，而是为了在动作空间中表达复杂、多峰、连续的条件分布。

---

## 4. Flow Matching 与 π0 的位置：连续流场生成动作

Flow Matching 的主线位置是：

```text
噪声动作
→ probability path
→ 速度场 v_θ
→ ODE sampling
→ 专家式动作块
```

π0 把这条线推进到 VLA / generalist robot policy 中：

```text
预训练 VLM
→ 视觉语言条件
→ flow matching action expert
→ 连续动作控制
```

它回答的问题是：

```text
当 VLA 面对连续高频机器人动作时，动作头如何从离散 token 走向连续流场生成？
```

---

## 5. Octo 的位置：开源通用机器人策略初始化

Octo 的主线位置是：

```text
大规模多机器人数据
→ 通用策略预训练
→ 语言 / 目标图像条件
→ 快速微调到新机器人和新任务
```

它回答的问题是：

```text
机器人策略能否像视觉模型一样，通过大规模多任务数据获得可迁移的策略初始化？
```

在本书中，Octo 不应被理解为“又一个 Transformer 模型”，而应放在“多任务、多平台、多条件策略”的位置。

---

## 6. OpenVLA 的位置：开源 VLA 与机器人动作 token

OpenVLA 的主线位置是：

```text
互联网视觉语言预训练
→ 机器人示范数据
→ 视觉语言动作统一模型
→ 动作 token 输出
→ 高效微调与部署
```

它回答的问题是：

```text
如何把视觉语言模型的语义泛化能力接到机器人动作生成上？
```

在本书中，OpenVLA 不是单纯“大模型章节”的例子，而是第15章 VLA 条件策略的代表模型。

---

## 7. World Model / WAM / JEPA 的位置：动作后果预测

World Model 的主线位置是：

```text
当前世界表示 h_t
→ 候选动作块 A_t
→ 未来世界表示 h_{t+1:t+H}
→ 风险 / 目标 / 可恢复性评估
```

WAM 强调动作条件：

```text
如果执行这个动作，世界会怎样？
```

JEPA 强调表示预测：

```text
预测任务相关表示，而不是重建所有像素细节。
```

它们回答的问题是：

```text
策略会生成动作之后，机器人能否在执行前预测动作后果？
```

## 9. 读者判断表

读到一个新机器人策略模型时，不要先问“它是不是 SOTA”，而应先判断：

```text
它主要解决分布偏移吗？
它主要解决动作多峰吗？
它主要解决动作块生成吗？
它主要解决历史 / 多模态上下文吗？
它主要解决跨任务泛化吗？
它主要解决动作后果预测吗？
```

如果不能回答这些问题，模型名再新，也没有真正进入本书的数学主线。

---

## 10. 一句话总结

> 现代机器人策略的发展，不是从 BC 到 VLA 的模型名堆叠，而是从“在专家数据上拟合动作”逐步推进到“在复杂上下文中生成动作，并预测动作执行后的世界变化”。
