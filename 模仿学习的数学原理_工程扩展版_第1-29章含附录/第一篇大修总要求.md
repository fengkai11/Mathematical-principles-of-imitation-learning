## 1. 第一篇的新定位

第一篇定位为：

> **模仿学习的基本范式：从动作拟合到执行分布。**

第一篇不是方法综述，而是本书的数学地基。它要回答：

> **如何让学习策略闭环执行后产生的行为分布接近专家？**

> **让学习策略诱导出的状态—动作分布接近专家诱导出的状态—动作分布。**

## 3. 数学写作硬规则

第一篇是数学原理书的开篇，不能写成概念散文或写作笔记。所有章节必须遵守以下规则。

### 3.1 定义先行

使用任何核心符号前，必须先交代：

```text
对象是什么；
符号怎么写；
属于哪个集合；
在本章中承担什么作用。
```

例如，不能直接写轨迹 $\tau=(s_1,a_1,\dots)$，必须先定义状态空间 $\mathcal{S}$、动作空间 $\mathcal{A}$，并说明 $s\in\mathcal{S}$、$a\in\mathcal{A}$。

### 3.2 小节之间必须有数学依赖关系

章节不能平铺概念。小节顺序必须体现对象依赖：

```text
先定义基本空间；
再定义轨迹；
再定义策略；
再定义环境转移；
再推出轨迹分布；
再定义状态访问分布；
再定义状态—动作占用分布；
最后给出模仿学习总目标。
```

每一节开头要承接上一节，结尾要自然引出下一节。

### 3.3 公式必须说明来源

如果公式是定义，要明确写“定义”。

如果公式由前面对象推出，必须给出推导过程或至少给出逐项来源说明。

例如轨迹分布：

$$
p_\pi(\tau)=p_0(s_1)\prod_{t=1}^{T}\pi(a_t\mid s_t)P(s_{t+1}\mid s_t,a_t)
$$

必须说明它来自：

```text
初始状态分布 p_0(s_1)
第 t 步策略项 pi(a_t|s_t)
第 t 步环境转移项 P(s_{t+1}|s_t,a_t)
按时间步连乘得到整条轨迹概率
```

不能只把公式放出来。

### 3.4 论断必须有证明或边界

如果出现“有限专家轨迹不能唯一确定专家策略”“BC 不直接保证 $\rho_{\pi_\theta}\approx\rho_E$”“单步验证误差不能保证闭环风险”等论断，必须采用如下形式：

```text
论断 / 命题：一句话说明结论。
直觉解释：先让读者知道为什么可能成立。
证明 / 推导：给出简化数学过程。
适用边界：说明这个结论在什么条件下更强，什么条件下可能减弱。
```

若论断只是局部补充，不必单独成为大节，可以放在相关小节内部，但仍要有证明或推导。

### 3.5 正文不能出现作者自我说明

正文中禁止出现类似：

```text
在写轨迹之前，必须……
否则公式会……
这一顺序很重要……
下面开始……
这里我想说明……
```

这些属于作者写作笔记，不是成书正文。应改为面向读者的客观叙述，例如：

```text
轨迹、策略和执行分布都建立在状态空间与动作空间之上。
```

### 3.6 公式格式规范

使用：

```markdown
**公式 (x.y)：公式名称**

$$
...
$$
```

禁止使用：

```text
\tag{}
<div class="math">
</div>
<span class="math">...</span>
```

行内公式必须简洁。长公式必须独立成块。

## 4. 第一篇核心数学范式

第一篇必须围绕三行公式展开。

### 4.1 策略诱导状态—动作分布

$$
\rho_{\pi}(s,a)=d_{\pi}(s)\pi(a\mid s)
$$

解释要求：

- $d_{\pi}(s)$ 表示策略 $\pi$ 闭环执行时访问到的状态分布；
- $\pi(a\mid s)$ 表示策略在状态 $s$ 下选择动作 $a$ 的条件分布；
- $\rho_{\pi}(s,a)$ 表示策略诱导出的状态—动作联合分布，也称 occupancy measure；
- 必须说明该公式为什么是“会到哪里”和“会做什么”的合成。

### 4.2 状态分布由策略闭环诱导

$$
d_{\pi}(s')=(1-\gamma)d_0(s')+\gamma\sum_s d_{\pi}(s)\sum_a\pi(a\mid s)P(s'\mid s,a)
$$

解释要求：

- $d_0$ 是初始状态分布；
- $P(s'\mid s,a)$ 是环境转移；
- $\gamma$ 是折扣因子或时间衰减权重；
- 必须说明这个递推式来自“初始状态来源 + 从过去状态经动作转移而来”。

### 4.3 模仿学习总目标

$$
\min_{\pi}D(\rho_{\pi},\rho_E)
$$

解释要求：

- $\rho_E$ 是专家策略诱导出的状态—动作分布；
- $\rho_{\pi}$ 是学习策略诱导出的状态—动作分布；
- $D(\cdot,\cdot)$ 是分布距离；
- 第一篇不展开各种距离，只确立“模仿学习 = 让 $\rho_{\pi}$ 接近 $\rho_E$”这一母题。

## 6. 各章节职责

### 6.1 第1章：从专家轨迹到执行分布

第1章是全书数学地基章，必须按以下依赖链展开：

```text
状态空间 / 动作空间
→ 专家轨迹 / 专家数据集
→ 有限轨迹不能唯一确定专家策略
→ 策略定义
→ 环境转移与闭环执行
→ 策略诱导轨迹分布
→ 状态访问分布
→ 状态—动作占用分布
→ 模仿学习总目标
```

第1章必须包含至少两个推导：

1. 轨迹分布 $p_\pi(\tau)$ 的连乘形式如何由初始状态、策略项和环境转移项得到；
2. 状态访问分布递推式如何由“初始状态 + 从过去状态转移而来”得到。

有限专家轨迹不可唯一确定专家策略，可以作为“专家数据不是策略”的内部论断，不必单独成为大节，但必须给出证明过程。

### 6.2 第2章：Behavior Cloning：专家分布上的动作拟合

第2章必须说明 BC 是 $\rho_\pi\approx\rho_E$ 总目标的局部近似。

必须推导：

1. 最大似然到负对数似然；
2. 固定方差高斯动作模型下 NLL 与 MSE 的等价关系；
3. BC 目标为什么是在 $\rho_E$ 上拟合动作，而不是直接匹配 $\rho_{\pi_\theta}$。

### 6.3 第3章：分布偏移与 DAgger

第3章必须把“BC 的问题”和“DAgger 的修正”写成一问一答。

必须证明或推导：

1. 为什么 $d^{\pi_E}\neq d^{\pi_\theta}$ 会导致训练目标和执行目标不一致；
2. $O(T^2\varepsilon)$ 的最坏情形直觉来源；
3. DAgger 为什么通过采样 $s\sim d^{\pi_i}$ 改变训练数据来源；
4. DAgger 改善为 $O(T\varepsilon)$ 的直觉边界。

## 10. 验收标准

第一篇大修完成后，必须满足以下标准。

### 10.1 主线验收

读者读完第一篇后，能自然复述：

```text
模仿学习不是简单地拟合专家动作，
而是希望学习策略闭环执行后诱导出的 rho_pi 接近专家 rho_E。
策略通过环境转移 P(s'|s,a) 诱导自己的轨迹分布和状态分布。
BC 只是在专家分布上的动作拟合，
所以会遇到 d_pi 和 d_E 不一致的问题。
DAgger 通过让学习策略自己跑并请专家标注，
把训练数据推向学习策略会遇到的分布。
```

### 10.2 公式验收

第一篇必须能形成如下公式链：

```text
S, A
→ D_E
→ pi_theta(a|s)
→ P(s'|s,a)
→ p_pi(tau)
→ d_pi(s)
→ rho_pi(s,a)=d_pi(s)pi(a|s)
→ min_pi D(rho_pi,rho_E)
→ D_BC
→ J_BC(theta)=E_{rho_E}[-log pi_theta(a|s)]
→ d^{pi_E} != d^{pi_theta}
→ O(T^2 epsilon)
→ D_i = D_{i-1} union data from d^{pi_i}
→ O(T epsilon)
```
