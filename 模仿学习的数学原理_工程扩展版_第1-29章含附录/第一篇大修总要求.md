## 1. 第一篇的新定位

第一篇定位为：

> **模仿学习的基本范式：从动作拟合到执行分布。**

第一篇不是方法综述，而是本书的数学地基。它要回答：

## 3. 数学写作硬规则

第一篇是数学原理书的开篇，不能写成概念散文或写作笔记。所有章节必须遵守以下规则。

### 3.1 定义先行

使用任何核心符号前，必须先交代：

```text
对象是什么；
符号怎么写；
属于哪个集合；
在本章中承担什么作用。
```

例如，不能直接写轨迹 $\tau=(s_1,a_1,\dots)$，必须先定义状态空间 $\mathcal{S}$、动作空间 $\mathcal{A}$，并说明 $s\in\mathcal{S}$、$a\in\mathcal{A}$。

### 3.2 小节之间必须有数学依赖关系

章节不能平铺概念。小节顺序必须体现对象依赖：

```text
先定义基本空间；
再定义轨迹；
再定义策略；
再定义环境转移；
再推出轨迹分布；
再定义状态访问分布；
再定义状态—动作占用分布；
最后给出模仿学习总目标。
```

每一节开头要承接上一节，结尾要自然引出下一节。

### 3.3 公式必须说明来源

如果公式是定义，要明确写“定义”。

如果公式由前面对象推出，必须给出推导过程或至少给出逐项来源说明。

例如轨迹分布：

$$
p_\pi(\tau)=p_0(s_1)\prod_{t=1}^{T}\pi(a_t\mid s_t)P(s_{t+1}\mid s_t,a_t)
$$

必须说明它来自：

```text
初始状态分布 p_0(s_1)
第 t 步策略项 pi(a_t|s_t)
第 t 步环境转移项 P(s_{t+1}|s_t,a_t)
按时间步连乘得到整条轨迹概率
```

不能只把公式放出来。

### 3.4 论断必须有证明或边界

如果出现“有限专家轨迹不能唯一确定专家策略”“BC 不直接保证 $\rho_{\pi_\theta}\approx\rho_E$”“单步验证误差不能保证闭环风险”等论断，必须采用如下形式：

```text
论断 / 命题：一句话说明结论。
直觉解释：先让读者知道为什么可能成立。
证明 / 推导：给出简化数学过程。
适用边界：说明这个结论在什么条件下更强，什么条件下可能减弱。
```

若论断只是局部补充，不必单独成为大节，可以放在相关小节内部，但仍要有证明或推导。

### 3.5 正文不能出现作者自我说明

正文中禁止出现类似：

```text
在写轨迹之前，必须……
否则公式会……
这一顺序很重要……
下面开始……
这里我想说明……
```

这些属于作者写作笔记，不是成书正文。应改为面向读者的客观叙述，例如：

```text
轨迹、策略和执行分布都建立在状态空间与动作空间之上。
```

### 3.6 公式格式规范

使用：

```markdown
**公式 (x.y)：公式名称**

$$
...
$$
```

禁止使用：

```text
\tag{}
<div class="math">
</div>
<span class="math">...</span>
```

行内公式必须简洁。长公式必须独立成块。

## 4. 借鉴 RL 数学书的呈现风格

第一篇后续写作和修改，要借鉴《Book-Mathematical-Foundation-of-Reinforcement-Learning》前几章的教学呈现方式。这里借鉴的是**呈现形式**，不是照搬内容。

核心原则是：

```text
统一例子
→ 基本对象
→ 一个核心问题
→ 一个核心公式
→ 台阶式推导
→ 图示辅助
→ 证明分层
→ 章节递进
```

### 4.1 每章只解决一个“数学对象升级”问题

每章不能写成多个知识点的拼盘，而要完成一次清晰的数学对象升级。

第一篇三章的对象升级关系为：

```text
第1章：专家轨迹 → 策略 → 闭环执行 → occupancy
第2章：执行分布匹配目标 → 专家分布上的动作拟合 → BC
第3章：BC 训练分布 → 学习策略执行分布 → 分布偏移 → DAgger
```

每章开头必须明确：本章要把哪个对象升级成哪个对象。每章结尾必须回收这个升级是否完成。

### 4.2 统一例子贯穿，而不是每节换例子

第一篇应固定一个贯穿 toy example，用同一个例子解释状态、动作、轨迹、策略、BC、分布偏移和 DAgger。

建议统一例子为：

```text
二维机器人 / 简化机械臂到达任务
状态：二维位置、目标位置或简化观测
动作：二维速度、离散移动或末端位姿增量
专家：沿理想路径到目标
BC 策略：在专家轨迹附近拟合动作
分布偏移：第一步偏离后进入专家没覆盖区域
DAgger：采集走偏状态并重新标注
```

机械臂插入、自动驾驶等真实任务可以作为旁注或应用提示，但不要反复替换主例子，避免读者失去连续参照物。

### 4.3 先“动机例子”，再“定义”，再“公式”

每章和每个关键小节都应尽量采用以下顺序：

```text
先给一个极简例子；
再提出该例子暴露的问题；
再定义解决这个问题所需的数学对象；
再写公式；
最后解释公式如何回到例子。
```

不要一上来堆符号。读者应先知道为什么需要这个对象，再看到对象的定义和公式。

例如第3章不要直接从 $d^{\pi_E}\neq d^{\pi_\theta}$ 开始，而应先说明：BC 策略第一步走偏后，后续看到的状态已经不再来自专家轨迹附近。然后再定义训练分布和执行分布。

### 4.4 公式采用“台阶式推导”

核心公式不能只给结果，要拆成台阶。

例如轨迹分布应按以下台阶展开：

```text
第 1 步：初始状态来自 p_0(s_1)
第 2 步：给定 s_t，动作来自 pi(a_t|s_t)
第 3 步：给定 s_t,a_t，下一状态来自 P(s_{t+1}|s_t,a_t)
第 4 步：把每个时间步相乘，得到整条轨迹概率
```

第一篇至少以下公式必须采用台阶式推导：

```text
p_pi(tau)
d_pi(s') 的递推式
rho_pi(s,a)=d_pi(s)pi(a|s)
J_BC(theta)=E_{rho_E}[-log pi_theta(a|s)]
固定方差高斯 NLL → MSE
d^{pi_E} != d^{pi_theta}
O(T^2 epsilon)
DAgger 数据聚合公式
```

### 4.5 使用“直觉框 / 推导框 / 边界框”分层呈现

重要数学内容不要全部压进主线正文。为了保持可读性，可以使用分层框。

建议三类框：

```markdown
> 直觉框：用例子解释这个公式或结论在说什么。

> 推导框：说明公式从哪些定义推出。

> 边界框：说明结论在什么条件下成立，什么情况下会变弱。
```

主线正文负责保证读者连续读下去；推导框和边界框服务希望深入理解的读者。

例如 $O(T^2\varepsilon)$ 的主线正文只说明“早期错误会影响后续多个时间步”，详细求和推导放入推导框。

### 4.6 每章结尾要写“本章对象留下了什么问题”

每章结尾不能只做总结，还要引出下一章。

第1章结尾要回答：

```text
本章建立了 rho_pi 和 rho_E。
但还没有回答：如何用有限专家数据训练 pi_theta？
这引出第2章 BC。
```

第2章结尾要回答：

```text
本章说明 BC 在 rho_E 上拟合动作。
但还没有回答：学习策略自己执行后是否仍然处在 rho_E 覆盖区域？
这引出第3章分布偏移。
```

第3章结尾要回答：

```text
本章说明 DAgger 通过采集 d^{pi_i} 上的数据修正训练分布。
但它仍依赖专家标注和数据覆盖。
后续第二篇将讨论策略本身如何表达动作分布、多模态和轨迹层目标。
```

这一节是章节接力的硬要求。每章结尾必须同时回答：

```text
本章建立了什么对象？
它解决了什么问题？
它留下了什么问题，引出下一章？
```

## 5. 第一篇核心数学范式

第一篇必须围绕三行公式展开。

### 5.1 策略诱导状态—动作分布

$$
\rho_{\pi}(s,a)=d_{\pi}(s)\pi(a\mid s)
$$

解释要求：

- $d_{\pi}(s)$ 表示策略 $\pi$ 闭环执行时访问到的状态分布；
- $\pi(a\mid s)$ 表示策略在状态 $s$ 下选择动作 $a$ 的条件分布；
- $\rho_{\pi}(s,a)$ 表示策略诱导出的状态—动作联合分布，也称 occupancy measure；
- 必须说明该公式为什么是“会到哪里”和“会做什么”的合成。

### 5.2 状态分布由策略闭环诱导

$$
d_{\pi}(s')=(1-\gamma)d_0(s')+\gamma\sum_s d_{\pi}(s)\sum_a\pi(a\mid s)P(s'\mid s,a)
$$

解释要求：

- $d_0$ 是初始状态分布；
- $P(s'\mid s,a)$ 是环境转移；
- $\gamma$ 是折扣因子或时间衰减权重；
- 必须说明这个递推式来自“初始状态来源 + 从过去状态经动作转移而来”。

### 5.3 模仿学习总目标

$$
\min_{\pi}D(\rho_{\pi},\rho_E)
$$

解释要求：

- $\rho_E$ 是专家策略诱导出的状态—动作分布；
- $\rho_{\pi}$ 是学习策略诱导出的状态—动作分布；
- $D(\cdot,\cdot)$ 是分布距离；
- 第一篇不展开各种距离，只确立“模仿学习 = 让 $\rho_{\pi}$ 接近 $\rho_E$”这一母题。

## 7. 各章节职责

### 7.1 第1章：从专家轨迹到执行分布

第1章是全书数学地基章，必须按以下依赖链展开：

```text
贯穿例子
→ 状态空间 / 动作空间
→ 专家轨迹 / 专家数据集
→ 有限轨迹不能唯一确定专家策略
→ 策略定义
→ 环境转移与闭环执行
→ 策略诱导轨迹分布
→ 状态访问分布
→ 状态—动作占用分布
→ 模仿学习总目标
```

第1章必须包含至少两个推导：

1. 轨迹分布 $p_\pi(\tau)$ 的连乘形式如何由初始状态、策略项和环境转移项得到；
2. 状态访问分布递推式如何由“初始状态 + 从过去状态转移而来”得到。

有限专家轨迹不可唯一确定专家策略，可以作为“专家数据不是策略”的内部论断，不必单独成为大节，但必须给出证明过程。

第1章结尾必须留下问题：已经定义了 $\rho_\pi$ 和 $\rho_E$，但还没有说明如何从有限专家数据训练策略，引出第2章。

### 7.2 第2章：Behavior Cloning：专家分布上的动作拟合

第2章必须说明 BC 是 $\rho_\pi\approx\rho_E$ 总目标的局部近似。

建议结构：

```text
贯穿例子：把专家轨迹拆成训练样本
→ BC 数据集
→ 经验风险目标
→ MLE 到 NLL
→ 固定方差高斯下 NLL 到 MSE
→ BC 的专家分布目标
→ BC 不直接匹配 rho_pi 的证明
→ 本章留下的问题：执行时分布变了怎么办？
```

必须推导：

1. 最大似然到负对数似然；
2. 固定方差高斯动作模型下 NLL 与 MSE 的等价关系；
3. BC 目标为什么是在 $\rho_E$ 上拟合动作，而不是直接匹配 $\rho_{\pi_\theta}$。

### 7.3 第3章：分布偏移与 DAgger

第3章必须把“BC 的问题”和“DAgger 的修正”写成一问一答。

建议结构：

```text
贯穿例子：BC 策略第一步走偏
→ 训练分布与执行分布
→ 分布偏移的数学表达
→ 动作误差如何改变状态分布
→ 专家验证误差为什么不能保证闭环风险
→ O(T^2 epsilon) 的直觉推导
→ DAgger：让学习策略自己暴露问题
→ DAgger 数据聚合公式
→ DAgger 不是普通数据增强
→ O(T epsilon) 的直觉
→ 工程边界
→ 第一篇总结
```

必须证明或推导：

1. 为什么 $d^{\pi_E}\neq d^{\pi_\theta}$ 会导致训练目标和执行目标不一致；
2. $O(T^2\varepsilon)$ 的最坏情形直觉来源；
3. DAgger 为什么通过采样 $s\sim d^{\pi_i}$ 改变训练数据来源；
4. DAgger 改善为 $O(T\varepsilon)$ 的直觉边界。

第3章结尾必须完成第一篇收束，并引出第二篇：策略本身如何表达动作分布、多模态和轨迹层目标。

```text
模仿学习不是简单地拟合专家动作，

```
