# 全书核心命题链

> 本文件用于把全书从“公式集合”收束为“论证链”。每个核心命题都应该在正文中有定义、推导或反例，并在后续章节中被复用。

---

## 1. 为什么需要核心命题链？

模仿学习教材最容易出现的问题是：算法很多、公式很多、模型很多，但读者不知道哪些结论真正支撑全书。

本书的核心命题链用于回答：

```text
哪些结论必须理解？
哪些公式只是为这些结论服务？
哪些命题把一章自然推向下一章？
```

## 2. 十个核心命题

| 序号 | 核心命题 | 主要章节 | 主要作用 |
|---|---|---|---|
| 1 | 有限专家轨迹不能唯一确定专家策略 | 第1章 | 说明“看过一些示范”不等于恢复完整专家策略 |
| 2 | BC 的 MSE 最优解是条件均值 | 第5章 | 解释点估计为什么会在多峰动作下失败 |
| 3 | BC 的闭环误差会随时间累积 | 第3章 | 解释分布偏移为什么是核心问题 |
| 4 | DAgger 通过数据聚合缓解训练分布与执行分布不一致 | 第3章 | 从失败现象过渡到数据分布修正 |
| 5 | 多峰动作分布下，点估计会产生“平均动作”风险 | 第5章 | 引出概率策略、隐变量策略和生成式策略 |
| 6 | CVAE 的 ELBO 对应重建项与 KL 项 | 第6章 | 解释隐变量策略如何训练 |
| 7 | GAIL 判别器最优形式与密度比有关 | 第8章 | 连接判别器、occupancy matching 与隐式 reward |
| 8 | Offline IL 的主要风险来自 support mismatch | 第9章 | 解释离线数据覆盖和恢复数据的重要性 |
| 9 | Diffusion / Flow 的训练目标支持推理时生成动作 | 第11–12章 | 连接训练目标、采样过程和动作生成 |
| 10 | 世界预测误差小不必然推出控制效果好 | 第17章 | 说明世界模型必须和控制目标、风险验证结合 |

## 3. 命题之间的推进关系

```text
命题1：有限示范不等于完整策略
  ↓
命题3：BC 闭环误差会累积
  ↓
命题4：DAgger 用数据聚合修正执行分布
  ↓
命题2 / 命题5：即使数据覆盖改善，点估计仍会在多峰动作下失败
  ↓
命题6：CVAE 用隐变量和 ELBO 表达多种动作模式
  ↓
命题7：GAIL 从动作拟合提升到 occupancy matching
  ↓
命题8：离线数据覆盖决定策略能否安全泛化
  ↓
命题9：Diffusion / Flow 用生成过程表达复杂动作块
  ↓
命题10：只生成动作还不够，还要预测动作后果并验证风险
```

## 4. 每个命题的写作要求

每个核心命题在正文中应包含四部分：

```text
1. 问题动机：为什么需要这个命题？
2. 正式表述：用清楚的数学语言写出结论。
3. 推导 / 证明 / 反例：不一定追求最形式化，但要让读者信服。
4. 适用边界：这个命题什么时候成立，什么时候不能滥用。
```

## 5. 与贯穿例子的对应关系

| 命题 | 推块入槽中的直观解释 |
|---|---|
| 命题1 | 看过几条专家推块轨迹，不代表知道所有可能位置下该怎么推。 |
| 命题2 | 左推和右推都可行时，MSE 可能学出一个正中间的坏动作。 |
| 命题3 | 一步推偏会让下一步看到更陌生的状态，误差继续放大。 |
| 命题4 | DAgger 让专家给“模型自己走到的偏差状态”补标签。 |
| 命题5 | 多种推法被平均后，可能既不是左推也不是右推。 |
| 命题6 | 隐变量可以表示不同推法模式，ELBO 让这个模型可训练。 |
| 命题7 | 判别器不是只看某一步动作，而是在比较策略和专家的访问分布。 |
| 命题8 | 离线数据没覆盖卡住状态，模型部署时就可能不知道如何恢复。 |
| 命题9 | 去噪或连续流不是魔法，而是把噪声动作逐步变成可执行动作。 |
| 命题10 | 预测方块轨迹很准，也不等于控制策略一定安全；还要看风险、目标和闭环验证。 |

## 6. 后续执行检查

后续逐章改造时，用以下清单检查：

- [ ] 本章是否服务至少一个核心命题？
- [ ] 本章公式索引是否标出核心公式、辅助公式、背景公式？
- [ ] 本章是否说明命题的适用边界？
- [ ] 本章是否用“推块入槽”解释命题直觉？
- [ ] 本章结尾是否说明这个命题把问题推向下一章哪里？

## 7. 一句话定位

> 全书最重要的不是读者记住所有公式，而是能沿着这十个命题解释：为什么模仿学习会从 BC 一步步走向生成式动作策略、VLA 和世界预测。
