# 全书导读：新版布局说明

> 本版将原来的线性章节结构重排为 **八篇、二十九章、九个附录**。调整目标不是推翻原稿，而是把已经扩展出的内容重新组织成一条更清楚的技术演进路线。
>
> 本轮修订进一步明确两条互相配合的主线：第一条是统一工程例子 **视觉引导机械臂抓取与放置任务**；第二条是第一篇到第六篇的 **数学对象升级链**。工程主线帮助读者把公式落回真实任务，数学主线帮助读者看到每一篇为什么必须出现。

## 1. 为什么要重新布局？

随着 Flow Matching、World Models / WAM / JEPA、Preference Alignment / DPO 以及工程部署内容被补入，全书已经不再只是一本“行为克隆到 Diffusion Policy”的入门教程，而是扩展为：

```text
模仿学习基础
→ 序列决策与轨迹分布
→ 分布匹配与奖励视角
→ 现代机器人策略模型
→ 长上下文与多模态条件策略
→ 世界预测与动作后果验证
→ 后训练、对齐与实机部署
→ 工程落地与可信评估
```

如果继续按追加方式把新内容放在后面，读者会觉得后半部分像“补丁”。新版布局改为分篇结构，目的是让每一组章节都有清晰的问题意识和数学承接。

但仅有分篇还不够。一本数学原理教材还需要一个反复回到的统一例子，否则读者容易觉得自己在读 29 个相关但分散的主题。因此，本版将 **视觉引导机械臂抓取与放置** 设为全书工程主线：

```text
人类遥操作示范
→ 记录图像、本体状态、夹爪状态和动作
→ 学习观测到动作的策略
→ 闭环执行抓取与放置
→ 从失败、接管、偏好和回放中继续改进
```

这条主线不是为了把本书改成机械臂项目手册，而是为了让每个数学概念都有稳定落点：公式在说什么，符号对应什么工程对象，忽略这个问题会导致哪种机器人失败。

## 2. 第一篇到第六篇的数学对象升级链

本书前六篇不是六个并列专题，而是一条数学对象逐步升级的链：

```text
πθ(a|o)
→ pπ(τ)
→ ρπ(s,a)
→ pθ(A_t|o_t)
→ πθ(a_t|c_t)
→ pφ(h_{t+1:t+H}|h_t,A_t,c_t)
```

这条链对应的问题升级是：

```text
单步动作模仿
→ 闭环轨迹分布
→ 专家行为分布匹配
→ 动作块与多峰动作生成
→ 历史、多模态和语言条件策略
→ 动作后果预测与策略验证
```

换句话说，前六篇的核心不是“依次介绍 BC、MDP、GAIL、ACT、Diffusion、VLA、World Model”，而是不断追问：

> 在什么分布下、给定什么条件、生成什么动作，并预测这个动作会造成什么后果？

## 4. 本次结构调整做了什么？

本次重排主要做了七件事：

1. 将 **IRL** 前移到 **GAIL** 之前，使第三篇形成“奖励反推 → 分布匹配 → 离线风险”的理论顺序。
2. 将 **Flow Matching** 放到 **Diffusion Policy** 之后，使它成为生成式动作策略的自然延伸。
3. 将原本偏架构综述的内容压缩进第五篇，使第五篇聚焦“上下文条件变量如何扩展”。
4. 将第六篇重新定位为“从动作模仿到世界预测”，快慢系统只作为世界预测进入实时系统后的工程补充。
5. 将 **从论文到实机** 移动到后训练与部署部分，避免打断前六篇数学主线。
6. 新增统一工程主线：视觉引导机械臂抓取与放置。
7. 新增并强化第一篇到第六篇数学主线，使全书从“方法清单”变成数学对象逐步升级的教程。

## 6. 三条推荐阅读路径

### 路径 A：完整教材路径

从第1章读到第29章。适合第一次系统学习模仿学习数学原理的读者。阅读时建议始终追问：这一章在机械臂抓取与放置任务中解决了哪种失败？

### 路径 B：工程快速路径

```text
第1章 → 第2章 → 第3章 → 第4章 → 第7章 → 第13章 → 第14章 → 第15章 → 第20章 → 第21章 → 第24章 → 第25章 → 第29章
```

适合已经有算法工程背景，希望快速理解“为什么现代机器人策略这样设计”的读者。

### 路径 C：现代机器人策略路径

```text
第7章 → 第8章 → 第9章 → 第13章 → 第14章 → 第15章 → 第18章 → 第19章 → 第20章 → 第21章
```

适合重点关注 ACT、Diffusion Policy、Flow Matching、VLA、World Model 和动作后果预测的读者。

### 路径 D：机械臂主线专项路径

```text
第1章 → 第2章 → 第3章 → 第4章 → 第5章 → 第6章 → 第7章 → 第13章 → 第14章 → 第16章 → 第20章 → 第25章 → 第26章 → 第27章 → 第29章
```

适合想把本书内容落实到“视觉引导机械臂抓取与放置”项目中的读者。读这条路径时，应重点关注观测、动作空间、数据覆盖、闭环误差、动作多模态、动作块、实机安全和数据闭环。

## 7. 公式编号说明

新版章节已按重排后的章号重新编号。正文章节公式采用：

```text
(章号.公式序号)
```

例如第14章中的第3个公式写作：

```text
(14.3)
```

附录仍采用：

```text
(附录字母.公式序号)
```

例如：

```text
(B.2), (I.5)
```

## 8. 一句话总纲

> 本书新版布局的核心，是从一个视觉引导机械臂抓取与放置任务出发，把模仿学习从专家数据上的单步动作模仿，逐步推进到闭环轨迹分布、专家行为分布匹配、动作块条件生成、多模态上下文策略、动作后果预测，以及可后训练、可部署、可评估、可持续改进的机器人策略工程体系。
