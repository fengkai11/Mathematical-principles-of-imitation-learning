# 全书导读：六篇版布局说明

> 本版将正书内容收束为 **六篇、二十一章、九个附录**。调整目标不是否定原第七、第八篇内容，而是把《模仿学习的数学原理》的正书边界重新收束到一条清楚的数学主线：从专家数据上的单步动作模仿，推进到闭环轨迹分布、专家行为分布匹配、动作块条件生成、多模态上下文策略和动作后果预测。
>
> 原第七篇、第八篇的后训练、实机部署、Sim-to-Real、OPE、C4/ADR 和数据闭环内容已从正书中剥离，作为工程扩展材料存档。

## 1. 为什么收束为六篇？

本书的目标是讲清楚模仿学习背后的数学原理，而不是把所有机器人学习工程环节都放进一本正书里。

原第七篇、第八篇内容很有价值，但它们的问题重心已经从“模仿学习的数学对象如何出现”转向“策略如何后训练、部署、评估、架构化和持续运营”。这些内容更适合后续单独整理为工程扩展册。

因此，正书现在收束为：

```text
模仿学习基础
→ 序列决策与轨迹分布
→ 分布匹配与奖励视角
→ 现代机器人策略模型
→ 长上下文与多模态条件策略
→ 世界预测与动作后果验证
```

这条线完整回答一个问题：

> 如何从专家示范中学习一个能够闭环执行、能够表达复杂动作分布、能够利用多模态上下文，并能预测动作后果的策略？

## 2. 全书统一工程例子

仅有分篇还不够。一本数学原理教材还需要一个反复回到的统一例子，否则读者容易觉得自己在读多个相关但分散的主题。因此，本书将 **视觉引导机械臂抓取与放置** 设为全书工程主线：

```text
人类遥操作示范
→ 记录图像、本体状态、夹爪状态和动作
→ 学习观测到动作的策略
→ 闭环执行抓取与放置
→ 预测动作后果、风险和失败模式
```

这条主线不是为了把本书改成机械臂项目手册，而是为了让每个数学概念都有稳定落点：公式在说什么，符号对应什么工程对象，忽略这个问题会导致哪种机器人失败。

## 3. 第一篇到第六篇的数学对象升级链

本书前六篇不是六个并列专题，而是一条数学对象逐步升级的链：

```text
πθ(a|o)
→ pπ(τ)
→ ρπ(s,a)
→ pθ(A_t|o_t)
→ πθ(a_t|c_t)
→ pφ(h_{t+1:t+H}|h_t,A_t,c_t)
```

这条链对应的问题升级是：

```text
单步动作模仿
→ 闭环轨迹分布
→ 专家行为分布匹配
→ 动作块与多峰动作生成
→ 历史、多模态和语言条件策略
→ 动作后果预测与策略验证
```

换句话说，本书核心不是“依次介绍 BC、MDP、GAIL、ACT、Diffusion、VLA、World Model”，而是不断追问：

> 在什么分布下、给定什么条件、生成什么动作，并预测这个动作会造成什么后果？

## 4. 六篇结构

| 篇章 | 核心问题 | 数学对象定位 | 机械臂主线中的对应问题 | 包含章节 |
|---|---|---|---|---|
| 第一篇：模仿学习的基本问题 | 模仿学习是什么？BC 为什么会失败？ | 从专家数据学习单步条件策略 $\pi_\theta(a\mid o)$ | 遥操作示范能否直接训练出抓取策略？ | 第1–4章 |
| 第二篇：序列决策与轨迹分布基础 | 为什么模仿学习不是普通监督学习？ | 策略闭环执行诱导轨迹分布 $p_\pi(\tau)$ | 为什么接近、对准、抓取、放置必须作为连续轨迹理解？ | 第5–9章 |
| 第三篇：经典模仿学习的分布匹配与奖励视角 | 如何从动作拟合走向奖励与分布匹配？ | 用 $r(s,a)$、$R(\tau)$、$\rho_\pi(s,a)$ 理解专家行为 | 专家抓取动作背后是否隐含安全、平滑、成功率等偏好？ | 第10–12章 |
| 第四篇：现代机器人策略模型 | 如何表达复杂、多模态、连续动作？ | 从单步动作到动作块条件分布 $p_\theta(A_t\mid o_t)$ | 同一个物体有多种抓法，如何生成稳定动作序列？ | 第13–16章 |
| 第五篇：从历史上下文到多模态条件策略 | 策略生成动作前应该依据什么上下文？ | 从 $o_t$ 扩展到 $h_t$ 与 $c_t^{\mathrm{VLA}}$ | 如何记住接触历史，并根据语言指令改变抓取目标？ | 第17–18章 |
| 第六篇：从动作模仿到世界预测 | 生成动作之后，如何预测后果并辅助验证？ | 动作条件世界预测 $p_\phi(h_{t+1:t+H}\mid h_t,A_t,c_t)$ | 如何预测夹爪闭合、物体滑落、碰撞和放置后果？ | 第19–21章 |

## 5. 六篇主线图

```text
第一篇：从专家数据到单步条件策略 πθ(a|o)
        ↓
第二篇：从单步动作拟合到 MDP、轨迹分布 pπ(τ) 和概率策略
        ↓
第三篇：从轨迹分布到 reward、occupancy measure ρπ(s,a) 和离线覆盖
        ↓
第四篇：从单步动作到动作块条件生成分布 pθ(A_t|o_t)
        ↓
第五篇：从当前观测到历史、多模态和语言上下文 c_t
        ↓
第六篇：从动作生成到动作条件世界预测 pφ(h未来|h当前,A_t,c_t)
```
