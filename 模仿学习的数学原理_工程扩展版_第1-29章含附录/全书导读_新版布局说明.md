# 全书导读：六篇版布局说明

> 本版将正书收束为 **六篇、十八章、九个附录**。收束的目标不是减少内容，而是让读者沿着一条清楚的主线理解模仿学习：从专家轨迹出发，先看到 Behavior Cloning 的简单与失败，再走向分布偏移、动作分布、隐变量、分布匹配、现代生成式动作策略、多模态上下文策略，最后进入动作后果预测。

---

## 1. 本书真正要回答的问题

模仿学习表面上是在问：

```text
专家怎么做，模型能不能照着做？
```

但这只是第一层问题。机器人一旦闭环执行，动作会改变下一步状态，状态又会改变后续动作。因此，本书真正追问的是：

> 如何从有限专家示范中学习一个能闭环执行、能表达多种合理动作、能利用历史和多模态上下文，并能预测动作后果的策略？

这句话决定了全书的六篇结构。

---

## 2. 全书主线：从动作拟合到动作后果预测

全书不是模型名列表，而是一条问题逐层升级的链：

```text
专家轨迹
  ↓
监督学习式动作拟合：Behavior Cloning
  ↓
闭环执行导致训练分布与执行分布不一致：分布偏移 / DAgger
  ↓
同一状态下不止一个合理动作：动作分布 / 多峰 / CVAE
  ↓
单步动作不够稳定：动作块 / ACT
  ↓
复杂连续动作需要生成过程：Diffusion Policy / Flow Matching
  ↓
策略需要历史、视觉、语言和任务条件：Transformer Policy / VLA
  ↓
只会输出动作还不够：World Model / WAM / JEPA 预测动作后果
```

读者可以把全书看成一个连续追问：

```text
模仿什么？
→ 在什么分布上模仿？
→ 输出单个动作还是动作分布？
→ 输出一步动作还是动作块？
→ 动作由什么上下文条件决定？
→ 执行动作后世界会怎样变化？
```

## 3. 全书统一贯穿例子：二维桌面机器人推块入槽

为了避免全书变成抽象公式堆叠，本书引入一个贯穿例子：**二维桌面机器人推块入槽**。

场景如下：

```text
桌面上有一个小方块、一个目标槽位、一个二维机器人末端执行器。
专家会推动方块进入槽位。
机器人可以观察自身位置、方块位置、目标位置，也可以扩展到图像观察和语言指令。
```

这个例子足够简单，可以承载状态、动作、轨迹、策略、分布偏移、动作多峰、离线覆盖和世界预测；又足够接近机器人操作，可以自然过渡到 ACT、Diffusion Policy、VLA 和 World Model。

它在全书中的作用如下：

```text
第1章：什么是状态、动作、轨迹、专家策略
第2章：BC 学专家在每个状态下推哪个方向
第3章：执行时偏了一点，进入专家数据没见过的状态
第4章：单步动作不够，要预测未来 H 步动作块
第5章：同一个状态下可以从左推，也可以从右推，动作是多峰的
第6章：隐变量 z 表示“选择左侧策略还是右侧策略”
第7章：专家到底在优化什么？距离短、碰撞少、动作平滑？
第8章：不显式学 reward，而是让轨迹分布像专家
第9章：离线数据没覆盖卡住后的恢复动作
第10章：ACT 一次输出一段推方块动作
第11章：Diffusion Policy 生成多种合理推法
第12章：Flow Matching 用连续流把噪声动作变成专家动作
第14章：Transformer 根据历史判断方块是否已经偏移
第15章：VLA 根据图像和语言“把红色方块推入槽”
第16章：只学动作不够，还要理解推了以后方块会怎么动
第17章：World Model 预测不同推法的后果
第18章：世界预测进入计划、验证和安全边界
```

第一篇中的二维点机器人仍可作为最小数学例子使用；但从全书层面看，“推块入槽”是统一机器人例子。

## 4. 第一篇到第六篇的数学对象升级链

全书前六篇不是六个并列专题，而是一条数学对象升级链：

```text
πθ(a|s)
→ dπ(s), ρπ(s,a)
→ pθ(a|s), πθ(a|s,z)
→ r(s,a), R(τ), ρπ(s,a)
→ pθ(A_t|c_t)
→ πθ(a_t|c_t^{VLA})
→ pφ(h_{t+1:t+H}|h_t,A_t,c_t)
```

对应的问题升级是：

```text
单步动作拟合
→ 闭环执行分布
→ 条件动作分布与多峰动作
→ 专家偏好与行为分布匹配
→ 动作块条件生成
→ 历史与多模态上下文条件策略
→ 动作条件世界预测
```

## 6. 全书核心命题链

本书不是公式罗列，而是由以下核心命题支撑：

1. 有限专家轨迹不能唯一确定专家策略。
2. BC 的 MSE 最优解是条件均值。
3. BC 的闭环误差会随时间累积。
4. DAgger 通过数据聚合缓解训练分布与执行分布不一致。
5. 多峰动作分布下，点估计会产生“平均动作”风险。
6. CVAE 的 ELBO 对应重建项与 KL 项。
7. GAIL 判别器最优形式与密度比有关。
8. Offline IL 的主要风险来自 support mismatch。
9. Diffusion / Flow 的训练目标解释了为什么推理时可以生成动作。
10. 世界预测误差小不必然推出控制效果好。

后续章节的公式、定义和例子都应围绕这条命题链服务。

## 8. 正书边界

本书重点是模仿学习的数学原理与机器人策略建模，不试图完整覆盖：

```text
强化学习全体系；
控制理论全体系；
机器人系统工程全流程；
Sim-to-Real 专题；
部署、监控、数据闭环平台；
大模型后训练与偏好对齐全流程。
```

这些内容与本书有关，但不作为正书主线展开。原第七篇、第八篇相关材料已作为工程扩展内容存档。

---

## 9. 一句话总纲

> 本书以“二维桌面机器人推块入槽”为贯穿例子，把模仿学习从专家数据上的单步动作拟合，逐步推进到闭环执行分布、条件动作分布、专家行为分布匹配、动作块生成、多模态上下文策略和动作后果预测。
