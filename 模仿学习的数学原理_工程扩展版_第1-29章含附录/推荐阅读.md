# 推荐阅读与问题驱动式阅读路径

> 本文档不是论文堆砌清单，而是和本书主线互动的阅读系统。读者读论文时，不必一开始追求全部细节，而应带着本书中的问题去读：这篇论文回答了模仿学习链条中的哪个问题？它对应哪个数学对象？它在“推块入槽”例子中解决哪类失败？

---

## 0. 使用方法

每篇推荐阅读都按四个问题组织：

```text
对应章节：本书中最相关的章节；
重点看什么：第一次阅读时最应该抓住的内容；
暂时不用深究什么：避免读者一开始被细节卡住；
它回答的问题：这篇论文在全书主线中的位置。
```

阅读顺序建议：

```text
先读本书章节
→ 再读该章推荐论文的摘要、图1、方法总览和损失函数
→ 回到本书公式地图，确认它对应哪个数学对象
→ 最后再看实验设置、失败案例和工程边界
```

# 第一层：基础入口——专家示范、BC 与分布偏移

## 1. Argall et al., 2009, A Survey of Robot Learning from Demonstration

- 对应章节：第1章。
- 重点看什么：demonstration 的来源、状态/动作表示、泛化问题、评价方式。
- 暂时不用深究什么：所有机器人示教系统的分类细节。
- 它回答的问题：专家示范到底给了什么？为什么专家轨迹不是完整专家策略？

## 2. Pomerleau, 1989, ALVINN: An Autonomous Land Vehicle in a Neural Network

- 对应章节：第2章。
- 重点看什么：早期端到端驾驶中，图像到转向控制的监督学习形式。
- 暂时不用深究什么：老系统的具体硬件和训练细节。
- 它回答的问题：Behavior Cloning 为什么直观、有效，但天然会遇到闭环执行风险？

## 3. Ross and Bagnell, 2010, Efficient Reductions for Imitation Learning

- 对应章节：第3章。
- 重点看什么：horizon、单步误差、闭环误差累积、state distribution mismatch。
- 暂时不用深究什么：完整理论证明中的所有 regret 技术细节。
- 它回答的问题：为什么 BC 的单步误差不能直接代表部署成功率？

## 4. Ross, Gordon, and Bagnell, 2011, DAgger

- 对应章节：第3章。
- 重点看什么：让当前策略 rollout，再请专家给当前策略访问状态打标签的 dataset aggregation 思想。
- 暂时不用深究什么：no-regret online learning 的完整证明。
- 它回答的问题：如果训练分布和执行分布不一致，能否通过数据采集方式修正？

# 第二层：动作表达——从点估计到多峰动作分布

## 5. Bishop, 1994, Mixture Density Networks

- 对应章节：第5章。
- 重点看什么：同一输入下输出多峰连续分布的思想。
- 暂时不用深究什么：具体混合密度网络的所有实现细节。
- 它回答的问题：当一个状态对应多个合理动作时，为什么需要分布而不是单点回归？

## 6. Kingma and Welling, 2013, Auto-Encoding Variational Bayes

- 对应章节：第6章。
- 重点看什么：encoder、decoder、prior、ELBO、重参数化。
- 暂时不用深究什么：VAE 的所有生成建模理论背景。
- 它回答的问题：隐变量模型如何被端到端训练？

## 7. Sohn et al., 2015, Conditional Variational Autoencoder

- 对应章节：第6章。
- 重点看什么：条件生成、近似后验、条件 prior。
- 暂时不用深究什么：图像生成任务的具体网络结构。
- 它回答的问题：如何在给定状态或观测条件下生成多种合理动作模式？

## 8. Florence et al., 2021, Implicit Behavioral Cloning

- 对应章节：第5章、第13章。
- 重点看什么：为什么显式 MSE 回归容易产生平均动作，implicit policy 如何表达多峰动作。
- 暂时不用深究什么：energy-based model 的全部训练技巧。
- 它回答的问题：BC 是否只能是简单 MSE？如何让 BC 也具备更强动作分布表达能力？

# 第三层：经典分布匹配与奖励视角

## 9. Ng and Russell, 2000, Algorithms for Inverse Reinforcement Learning

- 对应章节：第7章。
- 重点看什么：从专家行为反推 reward 的问题设定。
- 暂时不用深究什么：早期有限 MDP 下的全部求解细节。
- 它回答的问题：专家到底在优化什么？能否从行为中恢复 reward？

## 10. Ziebart et al., 2008, Maximum Entropy Inverse Reinforcement Learning

- 对应章节：第7章。
- 重点看什么：用最大熵轨迹分布描述专家行为偏好。
- 暂时不用深究什么：所有动态规划求解细节。
- 它回答的问题：reward 不唯一时，如何用概率分布表达“专家更偏好哪些轨迹”？

## 11. Ho and Ermon, 2016, Generative Adversarial Imitation Learning

- 对应章节：第8章。
- 重点看什么：occupancy measure matching、判别器、隐式 reward 的关系。
- 暂时不用深究什么：TRPO 优化器的所有实现细节。
- 它回答的问题：如果不显式恢复 reward，能否仍然让策略闭环行为分布接近专家？

## 12. Kumar et al., 2019 / 2020, Conservative Offline RL and Support Constraints

- 对应章节：第9章。
- 重点看什么：离线数据支持集、OOD action、distributional shift。
- 暂时不用深究什么：Offline RL 的所有算法变体。
- 它回答的问题：为什么固定离线数据上的策略不能随意选择数据外动作？

# 第四层：现代机器人动作策略——ACT、Diffusion、Flow

## 13. Zhao et al., 2023, Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware

- 对应章节：第10章。
- 重点看什么：Action Chunking with Transformers、动作块、temporal ensemble、低成本真实机器人示范。
- 暂时不用深究什么：双臂硬件平台的所有工程细节。
- 它回答的问题：为什么机器人策略不应每次只预测一步动作？动作块如何提升短时连续控制？

## 14. Chi et al., 2023, Diffusion Policy: Visuomotor Policy Learning via Action Diffusion

- 对应章节：第11章、第13章。
- 重点看什么：把视觉运动策略写成条件去噪扩散过程、receding horizon、动作空间中的多峰生成。
- 暂时不用深究什么：图像生成 DDPM 的所有背景推导。
- 它回答的问题：如何在动作空间中表达复杂、多峰、连续的条件动作块分布？

## 15. Lipman et al., 2022, Flow Matching for Generative Modeling

- 对应章节：第12章。
- 重点看什么：probability path、velocity field、从噪声分布到数据分布的连续流。
- 暂时不用深究什么：一般生成模型中的全部数学推广。
- 它回答的问题：能否把动作生成看成连续速度场，而不是离散去噪步骤？

## 16. Black et al., 2024, π0: A Vision-Language-Action Flow Model for General Robot Control

- 对应章节：第12章、第15章。
- 重点看什么：预训练 VLM + flow matching action expert，如何输出连续动作并支持泛化机器人控制。
- 暂时不用深究什么：所有大规模训练配方和平台细节。
- 它回答的问题：Flow Matching 如何从“动作生成方法”进入 VLA / generalist robot policy 主线？

# 第五层：长上下文、多模态与通用机器人策略

## 17. Chen et al., 2021, Decision Transformer

- 对应章节：第14章。
- 重点看什么：把轨迹建模成序列，利用 return-to-go、state、action token 进行条件建模。
- 暂时不用深究什么：所有离线 RL benchmark 细节。
- 它回答的问题：策略能否被看成扩展上下文上的条件序列模型？

## 18. Brohan et al., 2023, RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control

- 对应章节：第15章。
- 重点看什么：如何把视觉语言模型适配到机器人动作输出。
- 暂时不用深究什么：Google 内部数据和系统细节。
- 它回答的问题：视觉、语言和动作如何进入统一策略模型？

## 19. Octo Model Team, 2024, Octo: An Open-Source Generalist Robot Policy

- 对应章节：第15章。
- 重点看什么：Open X-Embodiment 数据、通用机器人策略、语言/目标图像条件、快速微调。
- 暂时不用深究什么：所有 architecture ablation 细节。
- 它回答的问题：通用机器人策略如何在多平台、多任务、多传感器之间共享策略初始化？

## 20. Kim et al., 2024, OpenVLA: An Open-Source Vision-Language-Action Model

- 对应章节：第15章。
- 重点看什么：7B 开源 VLA、视觉编码器 + 语言模型 + 动作 token、大规模机器人示范和高效微调。
- 暂时不用深究什么：全部 LoRA / quantization 工程细节。
- 它回答的问题：开源 VLA 如何把视觉语言预训练和机器人动作示范连接起来？

## 21. Black et al., 2024, π0: A Vision-Language-Action Flow Model for General Robot Control

- 对应章节：第15章、第12章。
- 重点看什么：VLA 和 flow matching action head 的结合。
- 暂时不用深究什么：所有数据混合比例和训练基础设施。
- 它回答的问题：当动作是连续高频控制时，VLA 为什么需要比离散动作 token 更适合连续控制的 action head？

# 第六层：世界模型、JEPA 与动作后果预测

## 22. Ha and Schmidhuber, 2018, World Models

- 对应章节：第16章、第17章。
- 重点看什么：用 latent dynamics 建模环境，并在模型中辅助决策。
- 暂时不用深究什么：早期游戏环境的具体实现。
- 它回答的问题：为什么智能体需要内部世界表示，而不只是反射式策略？

## 23. LeCun, 2022, A Path Towards Autonomous Machine Intelligence

- 对应章节：第16章、第17章。
- 重点看什么：预测世界、表征学习、JEPA 思想、非像素重建的动机。
- 暂时不用深究什么：完整认知架构中的所有模块争论。
- 它回答的问题：为什么面向真实世界的智能系统需要预测世界表示？

## 24. Bardes et al. / Meta AI, 2023–2024, I-JEPA / V-JEPA

- 对应章节：第17章。
- 重点看什么：在表示空间中预测，而不是重建所有像素细节。
- 暂时不用深究什么：所有自监督视觉训练技巧。
- 它回答的问题：世界预测为什么可以预测任务相关表示，而不一定预测完整图像？

## 25. Action-Conditioned Video / World Model 相关工作

- 对应章节：第17章、第18章。
- 重点看什么：当前状态 + 候选动作如何预测未来状态、视频或 latent 表示。
- 暂时不用深究什么：所有视频生成指标。
- 它回答的问题：机器人怎样在执行前比较不同候选动作的后果？

## 路线 D：围绕“推块入槽”例子读

```text
专家轨迹是什么？读 Argall / BC
为什么推偏会越走越歪？读 DAgger
为什么左推右推会被平均？读 MDN / CVAE / Implicit BC
如何生成一段连续推法？读 ACT / Diffusion Policy / Flow Matching
如何根据语言和图像推指定方块？读 OpenVLA / Octo / π0
如何预测推了以后会不会卡住？读 World Model / JEPA
```

# 阅读时的统一检查表

每读一篇论文，建议回答以下问题：

```text
1. 它解决的是分布偏移、动作多峰、动作块生成、多模态条件，还是动作后果预测？
2. 它的核心数学对象是什么？π(a|s)、ρπ(s,a)、p(A|c)、c^{VLA}，还是 p(h未来|h当前,A,c)？
3. 它的训练数据是什么？专家轨迹、离线数据、机器人多任务数据，还是无标签视频？
4. 它的推理过程是什么？单步回归、采样、去噪、ODE、序列解码，还是候选动作评估？
5. 它在推块入槽任务中解决哪类失败？推偏、平均动作、动作抖动、语言目标不清，还是无法预测卡住？
```

# 一句话总结

> 推荐阅读不是正文之外的附录，而是正文问题链的外部验证。读者读论文时，应始终把论文放回本书主线：它到底是在修正数据分布、增强动作表达、扩展上下文，还是预测动作后果？
