## 1. 总判断

当前正书已经覆盖模仿学习的主要数学内容：

```text
BC / DAgger
→ MDP / 轨迹分布 / 概率策略 / 隐变量 / CVAE
→ IRL / GAIL / Offline IL
→ ACT / Diffusion Policy / Flow Matching
→ Transformer Policy / VLA
→ World Model / World Action Model / JEPA / 世界预测进入策略系统
```

这些内容本身大体完整，但还需要始终围绕一条“数学对象升级链”组织。

核心问题不是缺少知识点，而是需要把每一篇之间的数学接力显性化：

```text
πθ(a|o)
→ pπ(τ)
→ ρπ(s,a)
→ pθ(A_t|o_t)
→ πθ(a_t|c_t)
→ pφ(h_{t+1:t+H}|h_t,A_t,c_t)
```

这条链就是六篇正书的骨架。

## 2. 第一篇到第六篇的统一数学主线

六篇不是六个并列专题，而是一条逐步升级的数学问题链：

| 篇章 | 核心数学对象 | 解决的问题 | 留下的问题 / 收束作用 |
|---|---|---|---|
| 第一篇：基本问题 | $\pi_\theta(a\mid o)$、$d^{\pi_E}$、$d^{\pi_\theta}$ | 行为克隆为什么像监督学习，又为什么闭环会失败 | 单步动作误差为什么不能解释整条轨迹失败 |
| 第二篇：序列决策与轨迹分布 | $M=(S,A,P,r,\gamma)$、$p_\pi(\tau)$、$J(\pi)$、$z$、ELBO | 策略如何通过动作改变未来，并诱导轨迹分布 | 如果单步动作拟合不够，应在什么层面匹配专家 |
| 第三篇：分布匹配与奖励视角 | $r(s,a)$、$R(\tau)$、$\rho_\pi(s,a)$、$\mathcal{C}_\epsilon(\mathcal{D})$ | 从动作拟合走向专家偏好、occupancy matching 和离线覆盖分析 | 在固定数据和复杂动作下，如何表达多峰动作分布 |
| 第四篇：现代机器人策略模型 | $A_t$、$p_\theta(A_t\mid o_t)$、去噪过程、速度场 | 从点估计升级为动作块和条件动作分布生成 | 动作生成前需要什么历史、多模态和语言上下文 |
| 第五篇：长上下文与多模态条件策略 | $h_t$、$c_t$、$c_t^{\mathrm{VLA}}$、$\pi_\theta(a_t\mid c_t)$ | 把策略条件变量从当前观测扩展为历史、视觉、语言和动作 token | 会生成动作不等于知道动作后果 |
| 第六篇：世界预测与策略验证 | $p_\phi(h_{t+1:t+H}\mid h_t,A_t,c_t)$、$F_\eta(h_t,a_t)$、风险评分 | 预测动作后果，并用于候选动作评估、短期 rollout、风险预测和安全边界 | 正书收束到“动作生成之后，必须预测后果” |

一句话总纲：

> 本书六篇正书的数学主线，是从专家数据上的单步条件策略 $\pi_\theta(a\mid o)$ 出发，经过闭环轨迹分布 $p_\pi(\tau)$、occupancy measure $\rho_\pi(s,a)$、动作块条件生成分布 $p_\theta(A_t\mid o_t)$、多模态上下文条件策略 $\pi_\theta(a_t\mid c_t)$，最终进入动作条件世界预测 $p_\phi(h_{t+1:t+H}\mid h_t,A_t,c_t)$。
