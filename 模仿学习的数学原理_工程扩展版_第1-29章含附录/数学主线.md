# 全书数学主线：第一篇到第六篇

本书正书边界为 **六篇、二十一章**。原第七篇、第八篇内容已从正书剥离，作为工程扩展材料存档。

本文件用于说明六篇正书如何围绕一条统一的数学对象升级链展开，帮助读者在阅读全书时始终抓住主线：模仿学习不是方法清单，而是从专家示范出发，逐步追问策略在什么条件下生成动作、如何在闭环中诱导执行分布、如何表达复杂动作分布，以及动作会造成什么后果。

---

## 1. 总体判断

本书六篇正书覆盖模仿学习的主要数学内容：

```text
专家轨迹 / 闭环执行分布 / BC / DAgger
→ 轨迹损失 / 概率策略 / 隐变量 / CVAE
→ IRL / GAIL / Offline IL
→ ACT / Diffusion Policy / Flow Matching
→ Transformer Policy / VLA
→ World Model / World Action Model / JEPA / 世界预测进入策略系统
```

这些内容共同服务于一条“数学对象升级链”：

```text
D_E
→ πθ(a|s)
→ pπ(τ)
→ ρπ(s,a)
→ pθ(A_t|o_t)
→ πθ(a_t|c_t)
→ pφ(h_{t+1:t+H}|h_t,A_t,c_t)
```

这条链就是六篇正书的骨架。

---

## 2. 第一篇到第六篇的统一数学主线

六篇不是六个并列专题，而是一条逐步升级的数学问题链：

| 篇章 | 核心数学对象 | 解决的问题 | 留下的问题 / 收束作用 |
|---|---|---|---|
| 第一篇：基本范式：从动作拟合到执行分布 | $D_E$、$\pi_\theta(a\mid s)$、$P(s'\mid s,a)$、$p_\pi(\tau)$、$d_\pi(s)$、$\rho_\pi(s,a)$ | 模仿学习为什么不是普通监督学习；BC 为什么只是专家分布上的动作拟合；DAgger 如何修正训练分布 | 既然要闭环执行，策略本身如何表达动作分布、不确定性与轨迹层目标 |
| 第二篇：动作分布、轨迹损失与隐变量策略 | $J_{traj}$、$\pi_\theta(a\mid s)$、$p_\theta(a\mid s)$、$z$、ELBO | 从单步动作误差推进到轨迹层目标、概率策略、隐变量与 CVAE | 如果要匹配专家行为分布，是否可以从 reward 或 occupancy matching 角度理解 |
| 第三篇：分布匹配与奖励视角 | $r(s,a)$、$R(\tau)$、$\rho_\pi(s,a)$、$\mathcal{C}_\epsilon(\mathcal{D})$ | 从动作拟合走向专家偏好、occupancy matching 和离线覆盖分析 | 在固定数据和复杂动作下，如何表达多峰连续动作分布 |
| 第四篇：现代机器人策略模型 | $A_t$、$p_\theta(A_t\mid o_t)$、去噪过程、速度场 | 从点估计升级为动作块和条件动作分布生成 | 动作生成前需要什么历史、多模态和语言上下文 |
| 第五篇：长上下文与多模态条件策略 | $h_t$、$c_t$、$c_t^{\mathrm{VLA}}$、$\pi_\theta(a_t\mid c_t)$ | 把策略条件变量从当前观测扩展为历史、视觉、语言和动作 token | 会生成动作不等于知道动作后果 |
| 第六篇：世界预测与策略验证 | $p_\phi(h_{t+1:t+H}\mid h_t,A_t,c_t)$、$F_\eta(h_t,a_t)$、风险评分 | 预测动作后果，并用于候选动作评估、短期 rollout、风险预测和安全边界 | 正书收束到“动作生成之后，必须预测后果” |

一句话总纲：

> 本书六篇正书的数学主线，是从有限专家轨迹 $D_E$ 出发，先建立学习策略 $\pi_\theta(a\mid s)$ 如何通过环境转移 $P(s'\mid s,a)$ 诱导闭环轨迹分布 $p_\pi(\tau)$ 与 occupancy measure $\rho_\pi(s,a)$，再推进到动作块条件生成分布 $p_\theta(A_t\mid o_t)$、多模态上下文条件策略 $\pi_\theta(a_t\mid c_t)$，最终进入动作条件世界预测 $p_\phi(h_{t+1:t+H}\mid h_t,A_t,c_t)$。

## 3. 正书与存档的边界

正书只保留第1–6篇：

```text
第一篇：模仿学习的基本范式：从动作拟合到执行分布
第二篇：动作分布、轨迹损失与隐变量策略
第三篇：经典模仿学习的分布匹配与奖励视角
第四篇：现代机器人策略模型
第五篇：从历史上下文到多模态条件策略
第六篇：从动作模仿到世界预测
```

原第七篇、第八篇内容不再作为正书正文：

```text
后训练与偏好对齐
从论文策略到实机部署
Sim-to-Real
离线策略评估 OPE
C4 / ADR 系统架构
数据闭环与持续改进平台
```

这些内容仍有价值，但其问题重心已经从“模仿学习数学对象如何出现”转向“策略如何部署、评估、架构化和持续运营”。因此它们更适合作为工程扩展册或独立专题存档。
