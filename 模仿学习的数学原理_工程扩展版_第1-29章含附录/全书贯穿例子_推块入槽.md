# 全书贯穿例子：二维桌面机器人推块入槽

> 本文件用于统一全书的例子系统。它的作用类似强化学习教材中的 gridworld：不是追求工程复杂度，而是提供一个稳定、可反复使用的心智模型。

---

## 1. 场景设定

桌面上有一个小方块、一个目标槽位、一个二维机器人末端执行器。专家会推动方块进入槽位。

机器人可以观察：

```text
自身末端位置；
方块位置；
目标槽位置；
方块姿态；
可选的图像输入；
可选的语言指令。
```

机器人可以输出：

```text
二维位移；
二维速度；
短时动作块；
带历史条件的动作；
带视觉语言条件的动作；
候选动作块及其后果预测。
```

这个例子足够简单，可以承载状态、动作、轨迹、策略、分布偏移、动作多峰、离线覆盖和世界预测；又足够接近机器人操作，可以自然过渡到 ACT、Diffusion Policy、VLA 和 World Model。

---

## 2. 为什么不用更复杂的机械臂装配作为全书主例子？

机械臂装配、孔轴插入、治具摆放更接近真实工业问题，但它们引入了过多工程变量：三维姿态、力控、摩擦、接触、视觉标定、夹具误差、控制频率和安全策略。

这些内容很重要，但如果作为全书最小例子，会让读者在学习 BC、DAgger、GAIL、CVAE 之前就被工程细节淹没。

因此，本书采用两层例子：

```text
最小数学例子：二维点机器人 / 绕障；
全书贯穿机器人例子：二维桌面机器人推块入槽；
工程扩展例子：机械臂抓取、放置、插入、装配。
```

## 3. 各章如何使用这个例子

| 章节 | 例子中的问题 | 对应数学对象 |
|---|---|---|
| 第1章 | 专家如何推动方块入槽？记录下来的示范是什么？ | 状态、动作、轨迹、专家策略 |
| 第2章 | 在专家访问过的状态上，模型学习“该往哪个方向推”。 | BC、经验风险、NLL / MSE |
| 第3章 | 模型某一步推偏后，进入专家没演示过的位置。 | 分布偏移、DAgger |
| 第4章 | 单步动作太短视，需要输出未来几步推动动作。 | 动作块 $A_t$ |
| 第5章 | 同一位置既可以从左侧推，也可以从右侧推。 | 条件动作分布、多峰、MSE 均值陷阱 |
| 第6章 | 隐变量表示“选择左推模式还是右推模式”。 | 隐变量策略、CVAE、ELBO |
| 第7章 | 专家到底在优化什么：距离、碰撞、平滑还是成功率？ | reward、轨迹回报、reward ambiguity |
| 第8章 | 不显式恢复 reward，直接让访问分布像专家。 | occupancy measure、GAIL |
| 第9章 | 离线数据没录到卡住后的恢复动作。 | support mismatch、OOD action、recovery data |
| 第10章 | 一次输出一段推块动作，减少高频抖动。 | ACT、动作块、temporal ensemble |
| 第11章 | 从噪声中生成多种合理推法。 | Diffusion Policy、去噪生成 |
| 第12章 | 用连续速度场把噪声动作流向专家动作。 | Flow Matching、ODE sampling |
| 第13章 | 比较 BC、ACT、Diffusion、Flow 分别适合哪类推块失败。 | 策略模型对比 |
| 第14章 | 根据历史判断刚才是否推偏、是否需要纠正。 | Transformer Policy、历史上下文 |
| 第15章 | 根据图像和语言“把红色方块推入槽”生成动作。 | VLA、多模态条件策略 |
| 第16章 | 只输出动作不够，还要理解推了以后方块会怎样。 | 从动作模仿到世界预测 |
| 第17章 | 预测不同推法会导致入槽、卡住、滑开还是碰撞。 | World Model、WAM、JEPA |
| 第18章 | 用预测结果筛选动作，辅助计划、验证和安全边界。 | 动作后果验证、风险评分 |

## 4. 六篇中的角色变化

```text
第一篇：推块入槽是 BC 和分布偏移的例子。
第二篇：推块入槽变成动作多峰和动作块建模的例子。
第三篇：推块入槽变成专家偏好、occupancy matching 和离线覆盖的例子。
第四篇：推块入槽变成现代生成式动作策略的例子。
第五篇：推块入槽变成历史上下文和视觉语言条件策略的例子。
第六篇：推块入槽变成动作后果预测和风险验证的例子。
```

## 5. 写作使用规则

后续修改章节时，优先遵守以下规则：

1. 每章至少使用一次“推块入槽”例子解释本章核心对象。
2. 不要每次重新介绍完整场景，只根据需要引用。
3. 例子必须服务定义、公式、命题或反例，不能只当装饰。
4. 第一篇可以保留二维点机器人作为最小数学例子，但全书主线回到“推块入槽”。
5. 当章节讨论机械臂抓取、放置、插入时，应说明它是推块例子的工程扩展，而不是另起一条主线。

---

## 6. 一句话定位

> “推块入槽”不是为了降低本书的机器人味，而是为了让读者在理解每个公式时，都能问一句：这个数学对象对应机器人推方块时的哪一种失败、能力或判断？
