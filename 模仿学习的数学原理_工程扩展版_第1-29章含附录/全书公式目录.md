# 全书公式目录

> 作用：本文件作为全书公式的统一索引。每个核心公式只在首次出现处重点讲解；后续章节如果复用该公式，只直接引用公式编号或公式名称，不再重新定义、不再重复推导。

---

## 0. 维护规则

### 0.1 首次出现原则

一个公式第一次进入全书数学主线时，需要完整说明：

```text
公式解决什么问题；
公式中每个符号表示什么；
公式从哪些定义推出；
公式适用边界是什么；
它如何连接下一步主线。
```

后续章节再次使用该公式时，只需要写：

```text
由公式 (x.y) 可知……
沿用第 x 章中的 XXX 公式……
这里继续使用第 x 章已经定义的 XXX 对象……
```

除非公式含义发生变化，否则不要再次重点讲解、重新编号或重复推导。

### 0.2 核心公式与辅助公式分级

全书公式分为三类。

```text
A 类：主线核心公式
B 类：章节支撑公式
C 类：推导中间式 / 例子公式
```

A 类公式进入本目录；B 类公式可进入章节公式索引；C 类公式通常不进入全书目录。

一个公式是否进入全书目录，至少满足以下条件之一：

```text
1. 定义一个后续章节会反复使用的数学对象；
2. 给出一个核心训练目标或优化目标；
3. 支撑一个关键命题；
4. 建立篇章之间的数学衔接；
5. 是后续方法的统一抽象形式。
```

### 0.3 后文复用规则

后续章节复用已介绍公式时，禁止写成“重新教学”。正确写法是：

```text
沿用公式 (2.3) 中的 occupancy measure 写法……
第5章已经说明 MSE 的最优点估计是条件均值，下面直接使用该结论……
第6章已经给出隐变量边缘化公式，后文生成式策略都可以看作它的扩展……
```

错误写法是：

```text
再次完整定义同一个公式；
再次逐字解释已解释过的符号；
再次完整推导已经证明过的结论；
给同一个数学对象换一个公式编号重新出现。
```

### 0.4 本目录的更新方式

每当新增或重写章节时，必须检查：

```text
1. 是否新增了全书级核心公式；
2. 是否复用了已有公式但没有引用目录；
3. 是否把辅助公式误当核心公式反复编号；
4. 是否需要把新公式加入本目录。
```
